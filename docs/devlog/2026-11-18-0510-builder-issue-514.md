## Summary

Stopped before writing code, under the routine's conflict stop condition. The route model
(`KnownRoute`, `OpeningClearance`, `OpeningGraph`, and so `DebrisRouteGuard` and
`DebrisEscape`) tests debris only against openings, where two boxes share volume. A
straight tunnel is one box. A slab in its middle touches no opening, so the guard could
never hold it, even when it closes the last way out. That would break RUN-4. The fix
needs either a route-model change (partly in lane-c's `opening_graph.gd`) or a change to
the module geometry, which moves `output_hash`. The issue rules out both. Options are in
the comment on #514, which is now labelled `needs-human`.
