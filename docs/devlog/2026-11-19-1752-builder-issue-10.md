## Summary

- `tools/fetch_vendors_plugin.sh`: downloads `godotopenxrvendorsaddon.zip` from release
  5.2.0-stable (the asset library's release for Godot 4.6+), checks SHA-256
  `2a3958ff…718c4e35`, unpacks into the git-ignored `game/addons/godotopenxrvendors/`.
- `tools/check_quest_manifest.sh`: dumps the APK manifest with `aapt2` into the log and
  fails without `com.oculus.supportedDevices` listing `quest3`.
- `ci.yml`: script tests in `test`; fetch before and manifest check after the Quest export.
- Android Quest preset: Meta plugin on, Quest 2/Pro/3/3S, render model optional.
  `project.godot`: `xr/openxr/extensions/meta/render_model=true`. No `editor_plugins`
  entry: the GDExtension registers its export plugin itself, and an entry for a missing
  folder would make every non-Quest import rewrite `project.godot`.
- `ControllerModel` adds the plugin's `OpenXRFbRenderModel` when the class exists; a loaded
  Meta model hides the generic shape and the EXT manager, labels stay.
  `RenderModelReport`'s models line gains `vendor_models`.
- `tools/build.sh quest` stops early if the plugin was not fetched. Licence recorded.
