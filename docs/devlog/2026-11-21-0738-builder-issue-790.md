## Summary

- `dev_menu.json` gains **Hands** (right-handed / left-handed) and **Pitch** (normal /
  inverted) after Controls; the value words are optional text keys in the file. Confirming
  returns `hands:<left|right>` or `pitch:<normal|inverted>`. The menu opens on the settings
  in use.
- `DevMenuWiring` sets the game's one `ThumbstickMapping` (which the gripped sampler copies
  every frame, so both schemes follow), saves both in `ControlsChoice`'s file and keeps the
  menu open. Labels, haptics and the gripped models already read the mapping.
- `ControlsChoice` now holds `scheme`, `left_handed` and `invert_pitch`, each optional; saving
  one keeps the others. `main.gd`'s mapping line loads them in place (still 300 lines).
  There is no launch switch for hands or pitch, so the file alone sets them; no file means
  right-handed, normal pitch.
- `MELTDOWN_CONTROLS` now always carries `invert_pitch`, and is printed again with
  `"source":"menu"` on a Hands or Pitch change.
