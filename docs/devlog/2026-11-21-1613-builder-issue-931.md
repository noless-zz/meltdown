# 2026-11-21 Builder, lane-c, issue #931 (chain 2)

**Issue:** #931, wire the comfort vignette into the game (CMF-1, CMF-2, CMF-3, CMF-6, CMF-8, ARC-3).

## Summary

- New `game/vignette_wiring.gd` (`VignetteWiring`): each frame, after the rig is placed, it
  asks `ComfortVignette.strength` for the active preset (`comfort.preset`, so custom mode
  uses its own row) with the turn rate of the tick the view is showing and the speed
  interpolated like the rig's pose. It eases the shown strength towards that target and
  sets it on `XRRig/Camera/Vignette`.
- Snaps: a tick flagged `latest_tick_snapped` counts as no rotation, so a preset 1 snap
  yaw, snap pitch or auto-level roll snap adds nothing.
- Easing: new `game/xr/vignette_feel.gd` and `vignette_feel.json` (`smooth_seconds` 0.15,
  exponential, frame-rate independent). A rejected file prints once and falls back to
  the defaults. No per-preset multipliers were needed.
- Preset 4 (trigger NEVER or strength 0) drops to 0 at once. A paused session eases to 0.
- `main.gd`: one field and one hook line. To keep it at 300 lines (two tests guard
  that), two doc comments were shortened; no code changed there.

## Tests

Godot 4.7.2 in the session, as CI runs it: 2556 tests, 0 failed. New
