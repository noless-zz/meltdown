## Summary

- New `view/miner_label.gd` (`MinerLabel`, a child of `MinerView`) and
  `view/miner_label_look.json`: text, sight distance (25 m), show time (6 s), height over
  the miner (1.6 m), font size, pixel size, colour. Rejected files name the key and fall
  back to the built-in look.
- In sight = ship within the sight distance and `LineOfSight.clear` over the sim's walls,
  the same rule robots see by. Each miner (known by its fixed position) gets its label
  once per run; a new `MinerRescue` object is a new run. The label hides when its time is
  up or the miner leaves `trapped` (rescued). It is billboarded to face the head.
- `view/miner_view.gd`: creates the label and passes `walls` and `delta` on from
  `show_miners` (new optional parameters). `combat_wiring.gd`: the one call passes
  `session.sim.walls` and `delta`. Kept apart from #1230's hunks in `miner_view.gd`;
  a local merge of this branch with #1230 and #1232 has no conflicts.
- Reads only; never writes rescue or ship state (ARC-3, MP-2).
