  rows keep their places with no gap. The file stays under 300 lines (296).

  dev menu, below its lowest entry, with a heading (`info_title_text` in
  `dev_menu.json`, "Info") and dim lines: speed and boost, preset, seed or level, build.
  Each line is the text of the panel's own row, so it reads exactly as the panel did;
  it refreshes every frame while the menu shows. It cannot be selected. One line in
  `DevMenuWiring.attach` creates it.
