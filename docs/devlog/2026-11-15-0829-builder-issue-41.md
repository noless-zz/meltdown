## Summary

- `game/net/local_session.gd` (`LocalSession`): owns one `Sim` with one ship and a
  `ShipInputSource`. `advance(delta_seconds)` accumulates frame time and runs whole ticks,
  reading one input per tick, capped at `MAX_TICKS_PER_ADVANCE = 5`. Whole ticks beyond the
  cap are dropped and added to `dropped_seconds`; the fraction is kept so the view stays
  smooth. Exposes `interpolation_fraction` (0..1), `previous_ship()` and `current_ship()`
  (copies), and `replay`, which records every input fed to the `Sim`.
- `game/net/ship_input_source.gd` (`ShipInputSource`): the pull interface for the local
  ship's input; the base class returns idle input. The `xr/` mapping (#42) will subclass it.
- A whole tick is accepted within 1 µs (`TICK_EPSILON`): summed float frame times of
  72 Hz land just short of 1 s, and without the margin the 72 Hz test ran 59 ticks.
- Negative, NaN and infinite frame times are ignored rather than fed to the accumulator.
- Ship snapshots copy every script variable of `ShipState`, so the energy field from #46
  is carried along when it lands, without touching this file.
