## Summary

- `game/core/ship_tuning.gd` (`ShipTuning`, `RefCounted`): one typed float field per
  tuning value of `ShipState`, each with its unit documented. #40 was on `main`, so the
  wall values (`max_hull`, `radius`, `wall_restitution`, `wall_damage_per_speed`,
  `wall_damage_min_speed`) are included and no follow-up was needed.
- `ShipTuning.parse_json(text)` follows the `Replay.from_text` pattern: it always returns
  a tuning, with `error` set (and default values) for invalid JSON, a non-object, a
  missing key, an unknown key or a non-number value. Core opens no file.
- `apply_to(ship)` copies every value and fills energy and hull to their new maxima,
  clearing the afterburner lock: it is meant for a ship at the start of a run.
- `game/data/ships/default_ship.json`: every key with the current defaults.
- `game/tests/test_ship_tuning.gd`: 13 tests.
