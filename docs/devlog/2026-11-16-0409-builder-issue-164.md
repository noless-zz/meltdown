  `add(frame_seconds)`, `count`, `mean_ms`, `p99_ms` (nearest rank), `max_ms`, `dropped`,

  `check(max_dropped_fraction)` returns `""` or a message naming the measured and allowed

  fraction 0..1). `FrameStats.load_budget(hz)` reads it; `from_budget_json` parses text.
- `game/tests/test_frame_stats.gd`: ten tests covering every listed criterion plus budget
  validation and the report round trip.
