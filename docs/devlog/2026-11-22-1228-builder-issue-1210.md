  dimmer, for the others. The row count is the length of the ship's slot list each frame

  hold, speed, preset and level rows down, fewer hide them.

  already were ("Needle Gun", "Pulse Cannon", ...). `CombatWiring.weapon_names` feeds the
  panel. A file without a name falls back to the id made readable.
- `message_seconds` in `xr/status_panel_look.json` and the built-in fallback goes from 2
  to 3. A newer message already replaced an older one at once (#605); a test now pins it.
- `StatusPanel.show_weapon(id)` and `WEAPON_NONE` are replaced by `show_weapons(names,
  selected)`. The panel is 298 lines.
