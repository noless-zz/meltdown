## Summary

- `game/data/gen/debris.json` gains `min_robot_distance`, shipped as 2 m (one diameter of the
  default ship, radius 1 m). It is required like the other keys: missing is named, and
  anything but a number of metres 0..10000 is rejected with the key named.
- `DebrisPlan.place` takes an optional `RobotPlan`; `GeneratedLevel.build` passes the one it
  placed robots from. A drawn spot that keeps the start and reactor distances but comes within
  `entry radius + min_robot_distance + robot radius` of any robot spawn is skipped. An entry
  whose 64 draws found only such spots is dropped and the next entry is still tried (a
  "no room" entry still ends the placing, as before). `MineGenerator.debris_note` now reads
  `placed P of W debris entries: <reasons>`, with `N dropped for min_robot_distance` as one
  reason. Robot radii come from a resolved spawn's type, else the plan by id, else 0.
- With no robots the new check never rejects, so a level built without a robot plan draws
  exactly the same debris as before.
- `debris_plan.gd` was at 259 lines: `escape_spots`, `route_boxes` and their helpers moved
  unchanged to the new `game/gen/debris_spots.gd` (`DebrisSpots`). `debris_plan.gd` is now 243
  lines.
