## Summary

- New `game/net/latest_input_source.gd` (`LatestInputSource`, extends `ShipInputSource`):
  `set_input` stores a copy of the latest `ShipInput`; `next_input` returns a new object
  with those values on every tick, so the replay keeps one object per tick. Idle until
  set; `set_input(null)` returns to idle.
- `game/main.gd` now owns a `LocalSession` (seed 0) fed by a `LatestInputSource`
  (`input_source`, public for the controller reader in #61). `_process` calls
  `advance_frame(delta)`, which advances the session and puts `XRRig` at
  `interpolated_pose(previous_ship(), current_ship(), interpolation_fraction)`:
  position lerp, rotation slerp. Camera and hands stay tracked relative to the rig.
  The rig only reads the session's ship copies.
- The node now processes every frame, so the old text check in
  `test_xr_smoke_probe.gd` (`set_process(_smoke_probe.is_enabled())`) no longer held.
  It is replaced by a check that quitting stays behind `_smoke_probe.tick()` and that a
  disabled probe never asks to quit in 1000 frames.
- No `game/xr/` file changed (lane-c).

## Test results

Godot 4.7.2-stable, run locally exactly as CI does: 108 tests, 0 failed; the import adds
only the two new `.gd.uid` files, which are committed. A flat headless run of the main
scene with `--xr-smoke-frames=60` ran 60 frames with no script error.
