## Summary

- Robot weapons are their own files in `game/data/robot_weapons/` (`robot_pulse`,
  `robot_needle`, `robot_arc`, `robot_slug`). A separate folder, not `data/weapons/`, because
  every file there becomes a slottable part and needs a salvage look. `RobotDef.weapon` now
  resolves in `ROBOT_WEAPONS_DIR`; `salvage` still names ship weapons. The ship's files are
  untouched.
- `WeaponDef` optional keys `burst_shots`, `burst_pause_ticks`, `windup_ticks` (whole numbers;
  parse errors name the key). Missing keys keep one shot per interval, and the hash and replay
  line change only when a key is set.
- `RobotState.fire_at`: wind-up before each burst's first shot, restarted on any tick it could
  not fire; `is_winding_up()` for #604. Movement code is unchanged and runs every tick, so
  chasers and strafers keep moving through pauses and wind-ups.
- Hull: needler 12 to 20, hauler 60 to 40, so every generated-level type takes 3 to 5 pulse
  hits. Warden (test tunnel only) keeps 90.
- `LocalSession.for_level` gains `robot_weapon_dir`; `load_spawns` defaults to it.
