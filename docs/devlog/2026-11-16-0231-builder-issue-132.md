## Summary

- The view now decides from the tick, not from an angle: `ComfortWiring.latest_tick_snapped`
  is true while the latest tick flown was a snap on any axis, and `interpolated_pose` takes
  that flag instead of `snap_show_angle()` (removed). A 10-15 degree auto-level roll snap
  on preset 1 was slerped before, since the threshold was half a 30 degree snap.
- `ComfortInputFilter` (lane-c's file) gains two read-only flags, `produced_snap` and
  `produced_roll_snap`, set by `filter()`. Nothing else in that file changed.
- An auto-level roll snap now flies exactly one tick, like yaw and pitch snaps. Before, a
  hitch frame flew the held roll snap on every tick: a 12 degree bank ended at -24 degrees.
  The tests showed this; fixing it was needed for the 12 → 0 frame sequence.
- `main.gd` calls `_end_one_tick_if_flown()` after the second half of a split frame too,
  so a later tick in the same frame clears the snap flag. `carries_snap` was unused and is gone.
- The two snap-display tests moved from `test_main_comfort.gd` to the new
  `test_comfort_snap_display.gd`, which keeps both files under 300 lines.
