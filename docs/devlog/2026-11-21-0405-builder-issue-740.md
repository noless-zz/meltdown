## Summary

- New `game/xr/gripped_controls_model.gd` (`GrippedControlsModel`, `Node3D` built in code):
  kind `stick` (a shaft with a knob that tilts and twists about the grab point) or `throttle`
  (a fixed base with a handle that follows the hand). `show_pose(pose)` takes the grab-relative
  pose `GrippedStickMapping` reads and clamps it to the mapping's full deflection: stick tilts
  to `STICK_TILT_FULL_RAD`, twist to `STICK_TWIST_FULL_RAD` (measured with the mapping's own
  `stick_angles`), throttle travel per axis to `THROTTLE_FULL_M`. `release()` centres and
  dims it. Unshaded, alpha-blended, no shadows.
- New `game/xr/gripped_controls_look.gd` and `game/xr/gripped_controls_look.json`: colour,
  alpha, dimmed alpha (must be below alpha), stick length and radius, knob radius, throttle base
  and handle size, each range-checked; a bad file falls back to built-in values naming the field.
- No change to `main.gd`, `xr_rig.gd` or #739's files.
