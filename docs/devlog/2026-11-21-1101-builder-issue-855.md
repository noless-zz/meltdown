# Builder 2026-11-21 11:01, issue #855 (lane-c)

## Issue

#855: Thumbstick dead zone comes from the layout file (PLT-5, ARC-4, FLT-1, DEV-6).

## Summary

- New `game/xr/stick_dead_zone.gd` (`StickDeadZone`): reads the optional
  `"stick_dead_zone"` field of a layout file (0 to 0.5, default 0.15) and applies the
  radial dead zone. A bad value (not a number, out of range) gives 0.15 and a warning
  naming the file and the field; the rest of the layout still loads.
- `ThumbstickMapping` gains `stick_dead_zone` (applied to both sticks, either hand) and
  `warning`; `from_json` takes an optional source name and skips the field when reading
  bindings; `from_file` passes the path. `STICK_DEAD_ZONE` stays as the default and
  `apply_dead_zone` keeps its old call shape. Turn rates untouched.
- Both shipped layouts set `"stick_dead_zone": 0.15`.
- The helper is its own file so `thumbstick_mapping.gd` stays near 300 lines (309).
