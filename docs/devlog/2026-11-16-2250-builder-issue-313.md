## Summary

- `game/view/explored_boxes.gd` (`ExploredBoxes`): `visit(position)` marks every box that
  holds the position, walls included (`BoxBounds.holds(position, 0.0)`), so a point in a
  shared wall or an overlap marks both; `explored()` lists marked indices, lowest first.
- `game/view/map_wireframe.gd` (`MapWireframe`, static): `segments(union, explored)` takes
  each explored box's wall quads from `LevelFaces.quads`, finds the outline of the wall on
  each face (grid edges with wall on one side only), and joins collinear touching pieces,
  so a box edge shared by two faces, or a rim shared by two boxes, is one segment.
  Openings are cut against the whole union, so a passage into an unexplored box still
  reads as an opening. Output is a `PackedVector3Array` of endpoint pairs, the layout a
  line mesh takes.
- `MapWireframe.fit_to_cube(points, edge_m)`: uniform scale so the longest side of the
  bounds is `edge_m`, centred on the origin.
