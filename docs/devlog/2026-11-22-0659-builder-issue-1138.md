## Summary

- `RunnerCore.run_file` measures each file's wall time with `Time.get_ticks_usec` and
  returns it as `"ms"` (also for a file that fails to load).
- `RunnerCore.slow_lines` sorts files longest first (ties by name) and formats
  `SLOW <ms> <file>`.
- `run_tests.gd` prints the 15 slowest files and `Total time <ms> ms` after the
  unchanged totals line; exit code logic is untouched.
- `-- --only=<prefix>` runs only files whose name starts with the prefix.
- New fixture `fixtures/runner/takes_time.gd` (waits 20 ms) and
  `tests/test_runner_timing.gd` (5 tests).
