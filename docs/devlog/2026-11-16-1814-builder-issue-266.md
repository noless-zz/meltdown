## Summary

- Replay format version 9. A robot line now ends in one JSON object:
  `{"robot":{...},"weapon":{...}}`. "robot" holds every `RobotDef` key, the four
  optional movement keys included; "weapon" holds the resolved weapon's values (the same
  values the ship's weapon lines write) or `null` for an unarmed robot.
- One object rather than two JSON documents on the line, because a hand-written robot
  JSON may contain spaces, so splitting on spaces could not find where one ends.
- `RobotSpawn` gains `weapon` (optional constructor argument) and `spawn_all` passes it
  to `Sim.spawn_robot`, so `Replay.run` spawns each robot with exactly its `WeaponDef`.
- Version 8 robot lines (the robot's data alone) still read, as unarmed.
- `ReplayLines.weapon_data` is shared by the weapon lines and the robot line.
  `robot_def.gd` and `local_session.gd` untouched.
