## Summary

- `game/xr/map_shapes.gd` (new, `MapShapes`): the fit transform, glow material and marker
  ball moved out of `MapHologram`, which drops from 298 to 283 lines with the fire code added.
  `MapHologram.fit_transform` stays as a one-line delegate because tests call it.
- `game/view/map_fires.gd` (new, `MapFires`): one octahedron per fire, all in one mesh surface
  (one draw call). A marker spans the fire's fitted diameter but never less than `fire_size_m`,
  so a small fire on a large mine stays visible. A centre without a radius counts as radius 0.
- `MapHologram.show_fires(centres_m, radii_m)` keeps level-space copies and re-fits them on
  `build`; empty arrays remove them. `clear_route` leaves fires alone.
- `map_look.json` / `MapLook`: optional `fire_color` (yellow, `[1, 1, 0]`) and `fire_size_m`
  (0.012, range 0.002..0.05), validated like the other keys. Yellow keeps apart from the red
  blocked crosses and the orange ship marker, since fire is passable and must not read as
  blocked.
