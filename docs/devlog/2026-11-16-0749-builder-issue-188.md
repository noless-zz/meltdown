## Summary

- `game/core/robot_def.gd` (`RobotDef`, `RefCounted`), modelled on `WeaponDef`:
  `parse_json` reads `id`, `hull`, `radius`, `max_speed`, `acceleration`, `turn_rate`,
  `movement`, `weapon`, `salvage`. Numbers are range-checked (hull 1..10000, radius
  0.1..10 m, speed 0..200 m/s, acceleration 0..1000 m/s², turn rate 1..1440 deg/s);
  ids must be 1..64 characters of `a-z`, `0-9`, `_` (so they are safe file names);
  `movement` must be one of `hover`, `chase`, `strafe`. Missing, unknown or mistyped keys
  fail with the field named, and a rejected file leaves defaults.
- `values_hash()` over every field; `weapon_path()` returns `res://data/weapons/<id>.json`
  for the caller to read (core still opens no files).
- `game/data/robots/drone.json`: an original hovering drone that fires and drops the
  pulse cannon. Nothing from the original games (NAM-3).
- `sim.gd`, `ship_state.gd`, `replay.gd`, `weapon_def.gd` untouched (lane-a).
