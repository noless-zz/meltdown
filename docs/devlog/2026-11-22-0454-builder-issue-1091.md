## Issue

#1091: the bot run sweep flies a fully progressed ship beside the plain one (CRW-3, CRF-4,
CRW-1, RUN-1, DEV-6).

## Summary

- `bot_run_sweep.gd` takes `--profile=<path>` with `--fitting=<path>`. With both it flies
  the same run seeds twice: the plain ship file (lines and summary exactly as before),
  then the ship `RunShip` builds for a run level through `RunStartShip.build` (lines
  tagged `MELTDOWN_BOT_RUN_FITTED` / `MELTDOWN_BOT_RUNS_FITTED`), and ends with one
  `MELTDOWN_BOT_SHIP` line per ship: runs finished, level-1 escapes, mean hull left on
  level 1. Nothing is judged.
- New `tests/bot_sweep_ship.gd` reads the profile and fitting and builds the tuning. It
  refuses a missing or unreadable file, or a fitting `RunStartShip` would drop, with a
  message naming the file, so the sweep never flies the plain ship under the fitted name.
- `EscapeSweep.SeedResult` gained `hull` (hull left where the flight stopped).
- Fixtures `tests/fixtures/maxed_profile.json` (all 21 upgrades crafted; 12 crew: 1
  surveyor, 5 shield technicians, 2 cargo riggers, 4 reactor hands, which reaches every
  cap in `roles.json`) and `maxed_fitting.json` (arc lance and needle gun primary,
  glass-core shield, fused bulkhead, torsion drive, mine scanner and wide radar). "Best"
  is my reading: the arc lance has the highest damage per second, and each part is the
  top tier of its slot.

## Sweep, 20 runs both ways (run seeds 1 to 20)

```
godot --headless --path game -s res://tests/bot_run_sweep.gd -- --runs=20 --first=1 \
    --profile=res://tests/fixtures/maxed_profile.json --fitting=res://tests/fixtures/maxed_fitting.json
MELTDOWN_BOT_RUNS {"runs":20,"completed":11,"rate":0.5500,"levels_flown":63,"levels_escaped":54}
MELTDOWN_BOT_RUNS_FITTED {"runs":20,"completed":14,"rate":0.7000,"levels_flown":70,"levels_escaped":64}
MELTDOWN_BOT_SHIP {"ship":"plain","runs":20,"finished":11,"level1_escapes":15,"level1_mean_hull":65.36}
MELTDOWN_BOT_SHIP {"ship":"fitted","runs":20,"finished":14,"level1_escapes":17,"level1_mean_hull":117.02}
```

The maxed ship finishes 14 of 20 runs against 11 and escapes level 1 in 17 against 15.
Mean hull is absolute: the fused bulkhead raises max hull from 100 to 140, so the fitted
ship keeps about 84% of its hull on level 1 against about 65% for the plain one.
