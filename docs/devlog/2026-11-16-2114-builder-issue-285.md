## Summary

- `Sim.walls: BoxUnion` (null = open space) is now what the simulation keeps everything
  inside. The constructor's `BoxBounds` argument is wrapped as a one-box union, so
  `LocalSession`, `Replay` and the existing tests are unchanged. `Sim.bounds` stays as a
  read-only alias for the first box (the main-scene tunnel test reads it).
- New `Sim.set_walls(union) -> bool`: before the first tick only, like `equip` and
  `set_parts`, so a replay can rebuild the level from its header (#286). Refuses an empty
  union; null sets open space.
- Ships: `BoxUnion.contain_impact`. Robots: `keep_inside` with the box `box_for` picks
  where the robot ends up after moving. Salvage: moves, then `keep_inside` with the box
  `box_for` picks for `SalvageItem.RADIUS` where it ends up. Shots: removed when
  `walls.holds(position, 0.0)` is false.
- Picking the box after the move (as ships already do) is what lets a robot or a part
  pass through an opening; picking before would hold it in the box it started in.
- `SalvageItem.keep_inside(bounds)` split out of `advance` (no signature change;
  `advance(bounds)` behaves as before). Needed so `Sim` can pick the box after the move.
- `sim.gd` would have passed 300 lines, so the robot part of the tick moved to a new
  `core/robot_tick.gd` (`RobotTick.advance`, `RobotTick.remove_destroyed`), the same
  pattern as `ProjectileHits`. Mechanical move; behaviour unchanged.

## Test results

- Godot 4.7.2-stable in the run's scratch space; `--import` then `run_tests.gd` exactly as
  CI: 866 tests, 0 failed (7 new in `game/tests/test_sim_box_union.gd`). The eight
  `SCRIPT ERROR` lines are the expected ones. Every pinned hash and committed replay passed
  unchanged.
- New tests: constructor `BoxBounds` vs `set_walls` one-box union give the same hash
  every tick over 600 ticks with robot shots, a salvage drop and wall hits (and the test
  fails if any of those three never happens); in an L, an unarmed needler chasing the
  ship stays inside the union every tick and ends in the second leg, while the ship in
  the second leg is not moved; a part thrown hard inside the narrow tunnel of a
  room-and-tunnel level stays in the tunnel and comes to rest; a shot from the room flies
  through the opening to the tunnel's end and is removed there; a shot into the side wall
  is removed before its lifetime ends; two identical L runs hash alike; `set_walls`
  refuses an empty union and any change after the first tick.

## Open questions

- A chasing robot has no path finding: it heads straight at its target and slides along
  walls. In this L that gets it round the corner; in a level with the target behind a
  longer wall it could wedge. Worth a look before bots fly the G2 level. The chase test's
  needler is unarmed so the test is about walls, not about whether the ship survives.
- `BoxBounds.holds` compares 32-bit positions against 64-bit limits, so an object placed
  exactly on a wall can read a hair outside. The tests allow 1 mm; nothing in the
  simulation depends on it today.
