  unlock it". A game that never reaches the foreground (`dumpsys activity`) and starts no
  step within `-ForegroundGraceSeconds` (60 s) also skips, for a Quest lock the flags miss.
  The headset settings are restored either way. `docs/device-acceptance.md` says what an
  unattended run needs.

- Log: the buffer is raised to 16 MB (`logcat -G`), cleared, then the whole log streams to

  before the install and before each of two retries, as `update_quest.ps1` does (#589). A
  headset that stays gone fails with "the headset dropped off USB for a moment".
