## Summary

- New `game/xr/break_prompt.gd` (`BreakPrompt`, a `Node3D`): two unshaded `Label3D`s, a title
  and a body that says the whole minutes flown, how to dismiss (A in the headset, Enter on a
  desktop) and that reminders can be switched off. `show_if(reminder, xr_running)` shows it
  while the reminder is switched on and due; `acknowledge()` hides it and acknowledges the
  reminder, and does nothing while hidden so a shared button cannot reset the count.
  `apply_setting(reminder)` copies the file's `enabled` value into `BreakReminder.set_enabled`.
  It never touches the camera, the fade or the pause state.
- New `game/xr/break_prompt_look.gd` (`BreakPromptLook`) parses `game/xr/break_prompt.json`:
  switch, position, tilt, pixel size, fonts, colours and wording. Bad values name the field;
  a missing or rejected file falls back to built-in values with the error kept.
- Placement: 0.55 m ahead, 8.5 cm below the eye, tilted 9 degrees, above the status panel
  (which sits 18 cm down). Drawn without a depth test, one priority step above the panel's
  labels and below the reset fade.
