(CRF-2, RUN-7, ARC-1, ARC-2).

## Summary

- `core/run_state.gd`: `carried` (this level) and `banked` (this run) counts, an optional
  `ComponentList` to check kind ids, and an `error` field. `carry(collected)` replaces the
  carry; `advance(collected = {})` now returns the counts to bank and clears the carry (an
  empty argument banks the last `carry`); `lose()` drops the carry and leaves `banked`.
  Refusals change nothing and set `error`, naming an unknown kind id.
- `advance` used to return `bool`; it now returns a `Dictionary[String, int]` as the issue
  asks, so `test_run_state.gd` and `test_run_shaft_choice.gd` check `error` through a small
  helper instead. No game code called it.
- `can_suspend()`: escaped at least once, not over, nothing carried (#949).
- Carried and banked counts join `state_hash()` as sorted pairs, only when either is
  non-empty, so a run without components hashes exactly as before (pinned).
- New `meta/run_banking.gd`: `RunBanking.bank_escape(profile, counts)` wraps `Profile.bank`;
  `profile.gd` is untouched.
