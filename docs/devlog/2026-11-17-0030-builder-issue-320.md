## Summary

- `SpawnLoader.load_parts(weapon_dir)` (forwarded as `LocalSession.load_parts`): every
  `.json` file in the weapons folder, keyed by its file name, the id robots drop it under
  (`RobotDef.salvage`) and loadouts name it by. A rejected file or a name that is not a
  valid id is printed and left out; the other parts still slot.
- `LocalSession` takes the catalogue as a new last constructor argument and calls
  `Sim.set_parts` before the first tick, recording it in the replay (as #267 does). With no
  catalogue nothing changes, so committed replays and the `m1` / `m2` suite hashes keep
  their values.
- `LocalSession.for_level` builds the catalogue from its `weapon_dir`; `main.gd`'s default
  tunnel session passes `LocalSession.load_parts()`.
- The acceptance runner now passes a replay's own catalogue to the session it flies, so a
  replay recorded with parts flies with them and one without flies without.
- `test_main_hold_row.gd` no longer sets a catalogue itself.
