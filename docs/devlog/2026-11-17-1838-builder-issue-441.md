## Summary

- `SeedLevel` is now the one loader. `SeedLevel.load_inputs()` reads the modules, validator,
  reactor plan, loop bridges, robot plan (with the robot files), debris plan and ship
  tuning once; an instance then `generate`s a seed, builds `level_of` it (reactor, robots,
  debris) and `validate`s it with `RobotPlan.radii_by_id()` and the start module's boxes.
  The first broken file sets `error` as `<file name>: <message>`, the sweep's old format.
- `load_level` (what `--seed` flies) uses those three steps, so the flown level now has the
  generator's robots and debris; a broken robot or debris file prints the file's message
  and keeps the tunnel.
- `SeedSweep.run` builds every seed through the same `SeedLevel` instance; it gained an
  `overrides` argument (path to text) so a test can break one file. Its old loaders stay as
  one-line hand-ons to `SeedLevel` because other test files call them. A broken ship file now
  also fails the sweep (it used to fall back silently).
- `test_generated_robots.gd` reads robot texts through `SeedLevel.robot_texts()`.
- `main.gd` and `.github/` were not edited.
