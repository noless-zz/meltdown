## Open questions

- The skip line gives the short commit from the release text. During the window #1202
  describes, the text names a new commit while the APK is still the old one. In that window
  the line can name the newer commit for a headset that holds the older, identical APK. The
  decision itself goes by checksum only, so the right thing happens. Only the label can be
  wrong.
- On the headset, `adb install -r` should leave `base.apk` byte-identical to the downloaded
  APK. If a Quest OS ever rewrote it, the checksums would differ and the scripts would always
  install, which is today's behaviour. Worth confirming once with the owner's headset: a second
  run of `update_quest.ps1` should print the skip line.
