## Summary

- New `game/xr/control_scheme_switch.gd` (`ControlSchemeSwitch`): `--controls=` or the intent
  extra `meltdown_controls`, read like `LevelSwitch`/`FoveationSwitch`; default thumbsticks, a
  bad value ignored with a warning naming it. `map_values` picks the scheme each frame and
  prints `MELTDOWN_CONTROLS {"scheme":...,"left_handed":...}` once, on the first frame.
  Keyboard values carry no poses, so flat play always flies the thumbstick mapping (PLT-4).
- New `game/xr/gripped_sampler.gd` (`GrippedSampler`): grab point on grip past the mapping's
  threshold, release on let-go or lost tracking, pose relative to the grab in the rig's axes,
  then `GrippedStickMapping`. Afterburner on Y (B left-handed), named once as
  `AFTERBURNER_BUTTON`; fire on the stick hand's trigger. Hand settings follow the game's
  one `ThumbstickMapping`.
- `ControllerSampler` takes an optional third callable for each hand's pose and then adds a
  `poses` entry; `for_controllers` reads the controller nodes' transforms. This is the seam
  the issue names; without the callable nothing changes.
- `main.gd`: one line swapped for the scheme's `map_values`, one comment folded so the file
  stays at 300 lines. Reset, preset, label toggle and map still read the same values.
- Decision record 0004: "Gripped-stick scheme" paragraph, proposed until the headset check.
