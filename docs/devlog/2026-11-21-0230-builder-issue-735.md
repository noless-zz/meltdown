  view's. The camera's world rotation with the head taken out is what the game did
  (ship, comfort filter, shake), and only that is judged against CMF-3 and the preset
  caps, in the rig's own pitch, yaw and roll axes.
- The runner path (`sample_main`) reads the head from the camera's own transform under
  `XRRig`, which nothing in the game writes. The runner itself is unchanged.

  from the first frame's head pose) and `max_head_deg_s`. Over 5° the result line adds
  "the head turned up to N° (… °/s at most), not counted".

  the head pose is fixed, so the m1 steps fly the same replays with the same results.
