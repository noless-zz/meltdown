## Summary

- `tools/release_notes.sh <sha> <unix-time> [server|all]` prints the release body: the
  existing text, a blank line, then `Built: YYYY-MM-DD HH:MM UTC (YYYY-MM-DD HH:MM
  Asia/Jerusalem)`. The local time comes from `TZ=Asia/Jerusalem date`, so summer time
  follows the system time-zone data. The optional third argument keeps the two existing
  texts apart: `server` for the server-only publish (so a failed APK export never leaves a
  body that claims an APK), `all` (default) for the final text once every build is up.
