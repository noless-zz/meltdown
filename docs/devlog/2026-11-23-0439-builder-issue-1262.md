## Summary

- `ShipInput.slot_choice`: one small int, `SLOT_CHOICE_NONE` (default), `_SLOT_1`,
  `_SLOT_2`, `_DUMP`.
- `PartSlotting.apply` runs both slot controls for a ship; the rules table from the issue
  is in its comment, with one more row: a slot 1 or 2 choice with a slot still empty does
  nothing (the popup only opens with both full; the issue's table had no row for it).
  The choice acts once per change, as the click does once per press (#600), so a choice
  held for several ticks cannot swap in the next part flown through. It is read before
  the click on the same tick.
- With both slots full the click alone no longer replaces slot 1; it does nothing and
  leaves the choice to the popup (#1263).
- Dumped and replaced parts both drop `swap_drop_distance` behind the ship, moving with
  it, with `ignored_ship` set. A dump adds no event; a replace adds `PART_SLOTTED` as before.
- `ShipState.slot_choice_was` (not hashed, like `slot_was_held`). `ship_state.gd` is now
  300 lines.
- Replay format 19: the tick line's slot column is the click plus twice the choice (0 to
  7). Versions before 19 still accept only 0 or 1 there. A replay is written as 19 only
  when some input carries a choice, so every replay without one is written as before
  (`ReplayLines.frames_version`).
- Network protocol 4: the choice rides in flag bits 5 and 6; `encode_input` refuses an
  unknown choice. The issue's file list did not name `net/`, but
  `test_net_messages_carries_every_ship_input_property` requires every `ShipInput` field
  to travel, and MP-2 needs the choice to reach the host.
- Acceptance: new m2 step `slot_choice_replace` (before `bot_clears_g2_level`) with a new
  check `slot_choice_applied` (`acceptance/acceptance_slot_choice_check.gd`). The check
  re-flies the replay and, on each tick a choice acts, checks the slots, the hold and the
  dropped part (it must ignore the ship); it needs at least one replace and one dump.
  The recording: the bot takes a part and clicks it into the empty slot 2, takes the
  next and chooses slot 2 for it, takes the next and dumps it, then idles 30 ticks
  (289 ticks; ends with slots pulse cannon and arc lance).
