  that did not build prints none), or the runs do not add up to `RUNS`.
- New `tools/test_bot_run_rate.sh` (16 checks), run first by every `bot-runs` shard, as
  `test_bot_escape_rate.sh` is for the escape shards. The adding-up is a `tools/` script,
  not a GDScript helper.
