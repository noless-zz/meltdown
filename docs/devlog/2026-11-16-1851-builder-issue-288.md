## Summary

- New `game/view/level_faces.gd` (`LevelFaces`, `RefCounted`, static): the wall quads of
  a `BoxUnion`. Each face of each box is cut on a grid over every other box's footprint
  on it; cells inside another box (strictly inside on the face's own axis, so a box whose
  wall lies in the same plane does not open it) are dropped; the rest are merged greedily
  into rectangles. Each quad carries its box, axis and an inward normal. Also builds the
  edge strips: along each quad side that lies on its box's face edge, so the outline
  stops at openings.
- New `game/view/level_view.gd` (`LevelView`, `Node3D`): `build(union)` frees the old
  children and adds `Walls` (dark, non-emissive) and `Edges` (dimly emissive, lifted
  1 cm off the wall) as `ArrayMesh` instances. No lights. Triangles are wound so Godot
  draws the side the normal points to (checked against `SurfaceTool.generate_normals`).
- New `game/view/level_look.json`: wall colour, roughness, edge colour, edge energy
  (0..1, so the strips stay dim) and edge width. A missing or bad file is reported with
  the field named and the built-in look is used, as in `RobotView`.
- Split into two files so the geometry can be tested without meshes and each stays under
  200 lines. Not wired into `main.gd` (later lane-b issue).
