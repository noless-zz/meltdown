## Summary

- Replay format version 12: a replay may carry several `box` lines, kept in order and read
  as one `BoxUnion`. Versions 3 to 11 still allow at most one and keep the
  "'box' appears twice" message; every older version still reads.
- `Replay` keeps every box in `box_mins_mm` / `box_maxs_mm`, gains `add_box`,
  `set_boxes(mins, maxs) -> bool` (millimetres) and `walls() -> BoxUnion` (null without
  box lines). `has_box`, `box_min_mm`, `box_max_mm` and `bounds()` still describe the first
  box, so `LocalSession` and the acceptance runner need no change.
- `Replay.run()` builds its `Sim` with `set_walls(walls())`. The constructor builds the
  same one-box union from `bounds()`, so single-box replays hash as before.
