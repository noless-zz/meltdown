## Summary

- New `meta/safe_file_write.gd` (`SafeFileWrite`): the temporary-file, read-back, rename
  write that was inside `ProfileStore`. `ProfileStore.save` now calls it; its messages and
  its `stop_before_rename` seam are unchanged.
- New `meta/run_save.gd` (`RunSave`): `version`, `run_seed`, `next_level`, `ship`,
  `loadout` (the ship file's `{"primary": [...], "secondary": [...]}` shape, checked with
  `ShipLoadout.from_data`). Every missing, unknown or wrongly typed key is an error naming
  the key. The seed is written as a decimal string, since JSON numbers read back as floats
  and would round a seed above 2^53; every 64-bit seed reads back exactly.
- New `meta/run_save_store.gd` (`RunSaveStore`), default `user://meltdown_run.json`:
  `save`, `has_save`, `take` (reads and deletes; hands nothing out if it cannot delete, so a
  run never resumes twice), `discard` (removes the save and any leftover temporary file).
  A newer-version file is refused by `take` and `save` and left on disk. An unreadable file
  gives "no save" and a message and stays on disk until `discard`.
- No simulation, generator, view or xr change, so no replay or suite hash can change.
