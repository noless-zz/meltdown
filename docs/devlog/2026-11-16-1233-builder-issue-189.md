## Summary

- `LocalSession.load_tuning` now also reads `res://data/weapons/<id>.json` for every id
  the ship file's loadout names and resolves them (core opens no files). A missing or
  rejected weapon is printed and the ship flies unarmed with the file's other values.
- `LocalSession` equips a resolved loadout before tick 0 and puts it in the replay, so the
  real main scene starts with the pulse cannon and a saved replay reproduces the armed run.
- `LocalSession.current_projectiles()`: a new array of copies of `Sim.projectiles` after the
  latest tick. Each projectile keeps one copy for its whole flight, so `ProjectileView` can
  still tell a bolt it drew from a new one and blend it between ticks.
- New `game/combat_wiring.gd` (`CombatWiring`, beside `comfort_wiring.gd` because it reads
  `net/`): adds a `ProjectileView` under the main node, whose space is the simulation's
  (the tunnel node is offset by `TUNNEL_OFFSET`), and each frame feeds it the copies, the
  session's interpolation fraction and the camera's position for the bolt lights (#187).
- `main.gd`: three lines (292 to 296); #228 can add the robots to `CombatWiring`.
