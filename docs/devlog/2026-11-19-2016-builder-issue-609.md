## Summary

- New `game/view/headlight.gd` (`Headlight`, a `SpotLight3D`) and `headlight_look.json`:
  colour, energy, range, angle, distance attenuation and offset from the ship's centre. On by
  default, the only light with shadows (GFX-4).
- `game/xr/xr_rig.gd` adds the headlight under the rig origin and places it each frame at the
  cockpit frame's transform, which `RigViews.place` sets to the recentred head point (the ship's
  centre with the ship's axes). So the light is fixed to the ship and turns with it, not with
  the head, without touching `main.gd`. Without a frame (a rig on its own) it sits at the
  authored eye point facing -Z.
- New `game/view/level_look.gd` (`LevelLook`) parses `level_look.json` (every key required,
  errors name the key) and builds the wall material and the environment. `LevelView` and
  `TestTunnel` both use it, so all levels read alike.
- New `game/view/level_wall.gdshader`: one tint per surface class (floor, ceiling, wall, chosen
  by which way the face points), a grid of lines in world space worked out from the position
  (no textures), and distance darkening towards a near-black fog colour.
- Ambient light comes from the look file and is capped at 0.3 energy (shipped 0.12, LGT-1).
- Level walls now cast shadows, so the headlight stops at a wall instead of lighting the next
  room through it.

## Frame time

The m1 suite has no `frame_budget` check: it only checks the final hash. So I compared the
m1 desktop run's frame rate (`--print-fps`, Mesa llvmpipe software rendering under Xvfb,
OpenGL compatibility renderer, after the first ten seconds), before and after, four runs before
and two after:

- Before: 19.8, 19.9, 19.9, 20.0 fps (about 50.3 ms).
- After: 19.2, 19.9 fps (about 51.0 ms), roughly 1.5 % worse.
- First try with environment fog: about 16.5 fps, 17 % worse. Fog without shadows was just as
  slow, shadows without fog was not, so the darkening moved into the wall shader (20.2 fps).

These are software-rendering numbers, not the Quest. The headset numbers come from the
owner's run.
