## Summary

- `Sim.nearest_live_ship(point)`: nearest ship with hull above zero, ties to the lower
  index, null when none. `_advance_robots` hands it to each robot's `step`.
- `RobotState.step(target)`: no target means plain hover with no turning. With a
  target every movement first turns towards it by at most `turn_rate` per tick (rotation
  about the facing × direction axis, so no roll is added), then:
  - `hover`: unchanged from #204.
  - `chase`: approaches along its facing, scaled by how well it faces the target, at the
    fastest speed it can still stop from within the gap to its stand-off
    (`CHASE_STANDOFF_RADII` × own radius + ship radius); inside the stand-off it backs away.
  - `strafe`: circles about the world vertical (world x when straight above or below) in
    `strafe_direction`, inside `STRAFE_MIN_DISTANCE`..`STRAFE_MAX_DISTANCE` (10..20 m),
    pulled to the middle of the band.
  - Velocity changes by at most `acceleration` per tick and is capped at `max_speed`.
- `strafe_direction` (+1 even spawn index, -1 odd) is set at spawn, so it does not flip
  when an earlier robot dies; it is in the robot hash. Runs with no robots hash as before
  (the existing `REFERENCE_HASH` test still passes).
- Tuning numbers are named constants in `robot_state.gd`; `robot_def.gd` untouched.
