## Issue

#17 Guard the core and gen layer rules with a source scan test (ARC-1, ARC-3, MP-2).

## Summary

- `game/tests/test_layer_rules.gd` (new, 9 tests): reads every `.gd` file under
  `res://core/` and `res://gen/`, subfolders included, and fails with `<file>:<line>:`
  for each line that
  - extends anything other than `RefCounted` or a class declared in `core/` or `gen/`
    (also checked for inner classes and for `extends "res://..."`);
  - names an entry of the constant `FORBIDDEN_APIS` (the 13 entries of the issue);
  - calls `randf`, `randi`, `randf_range`, `randi_range` or `randfn` as a global, or
    `randomize`, `pick_random` or `shuffle` on anything.
- Comments are ignored, whole-line and trailing. A `#` inside a string is not a comment.
- `scan_source()` takes source text, so the other tests feed it snippets: every list
  entry, one realistic line per category, four forbidden base classes, a clean script,
  comments, and names that only look forbidden (`ShipInput.new()`, `PathNode`,
  `rng.randf()` on a seeded generator).
- The real scan also fails if it does not find `res://core/sim.gd`, so it cannot pass by
  scanning nothing.
- `game/tests/test_sim.gd`: `test_core_scripts_do_not_extend_node` removed.

No file under `game/core/` changed. `gen/` holds no script yet and is scanned as empty.

## Open questions

- Strings are scanned like code. An error message in `core/` that contains, say, the word
  `Node` at the start of a name would fail the test and need rewording. The issue only
  exempts comments, so this was kept strict.
- A string that continues over several lines is not followed: a `#` on a later line of
  it is taken as a comment start, so the rest of that line is not scanned.
- `rng.randomize()` on a `RandomNumberGenerator` is reported, although the issue only
  names globals and arrays. It seeds from the clock, so it breaks ARC-2 in the same way.
- A seeded shuffle helper in `core/` or `gen/` cannot be called `shuffle`; a name such
  as `seeded_shuffle` passes.
- `FileAccess` is not on the list (out of scope in the issue), so `Replay.save` and
  `load_file` pass.
- Still open: `*.gd.uid` files and `game/openxr_action_map.tres` appear after import and
  were left uncommitted here (#18).
