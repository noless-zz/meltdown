## Summary

- New `game/net/level_route.gd` (`LevelRoute`, `RefCounted`): `segment_held` (exact: the
  segment's spans inside each box shrunk by the radius must cover it), `opening_centre`,
  `chain` (breadth-first over `LevelDef.neighbours`, from every box holding the start at
  once, index order) and `waypoints` (just the target when the straight way is held,
  else the centre of each opening on the chain, then the target).
- `BotPilot` takes an optional `LevelDef` and a `set_goal(point)` for when no robot is
  left. Without a level the code path is the old one, unchanged (the straight-line turn
  maths moved into `_turn_towards`, same formula). With a level it steers to the next
  waypoint and thrusts towards a wanted velocity (capped at `ROUTE_SPEED` 10 m/s), so
  sideways drift at corners is cancelled; it only fires when flying straight at the robot.
- `core/` untouched; route and steering only read the `Sim`.

## Test results

  robot behind rock makes it thrust towards the opening and hold fire.
