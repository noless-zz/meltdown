Scheduled Builder run in lane-a. No open pull request closes a lane-a issue, so the run took

## Summary

- `game/tests/layer_scanner.gd` (new): the scanner moved out of `test_layer_rules.gd`, which
  would otherwise have grown past the 300-line limit. `test_layer_rules.gd` now extends it by
  path, so it keeps every constant and helper name.
- `SCANNED_DIRS` now includes `res://net`, with the same forbidden APIs, randomness rules and
  `RefCounted`-or-layer-class base rule as `core/` and `gen/`.
- New dependency rule (the table in `CLAUDE.md`): a scanned line that names a `res://view`,
  `res://xr` or `res://meta` path, or a `class_name` declared in those folders, is reported.
  A bad `extends` is reported once, not again as a dependency. `net/` using `core/` or
  `gen/` is allowed and not checked further.
- New tests: `net/` snippet with a clock call and global randomness, a path into each outside
  folder (and `res://viewer/` left alone), outside class names with lookalikes, and
  `global_classes` skipping inner classes. The main scan test also checks that it found
  `res://net/local_session.gd` and the `ThumbstickMapping` class in `xr/`, so it cannot pass
  on an empty set.
