## Summary

- New `game/xr/click_hold.gd` (`ClickHold`, `RefCounted`): fed once per frame with the
  button state and a time in seconds; `is_long_hold()` is true from the first frame that sees
  the button still down `MapHologram.HOLD_SECONDS` after it went down until release;
  `short_click_released()` is true on the release frame of a press that never got there.
  So every press is exactly one of the two. A release seen exactly at 0.40 s is a click,
  because no frame saw the button down that long.
- `ClickHold.steady_seconds()` is the one steady clock; `ComfortWiring.clock` defaults to it
  and tests still replace it there.
- `ComfortWiring.read_label_button` feeds its `click_hold` while the label button also shows
  the map and returns `short_click_released()`; `shared_click_hold()` hands the same object
  to the map, or null when `show_map` is remapped. The remapped path is unchanged
  (flip on press).
- `MapHologram.read` takes an optional `shared: ClickHold`; with it the map shows exactly
  while `is_long_hold()`; without it the old frame-delta `hold` runs as before.
- `game/main.gd` and `game/net/` unchanged. The map is still unwired; whoever wires it must
  call `map.read(..., comfort.shared_click_hold())` after `comfort.read_label_button`.

## Test results

- Godot 4.7.2-stable in the run's scratch space; `--import` then `run_tests.gd` exactly as
  CI: 989 tests, 0 failed (6 new in `game/tests/test_click_hold.gd`).
- New tests: 390, 400 and 410 ms presses each do exactly one thing (labels, labels, map); a
  1 s hold shows the map from the 400 ms frame to the frame before release and never flips;
  a 100 ms click flips once on release; frames of 5 ms, 50 ms, 50 then 5 ms, and 5 then
  50 ms give the same answers; remapped `show_map` flips on press and the map times its own
  control; 300 random presses with random 2 to 60 ms frames never give both answers.
