## Issue

#1246: menu row "Return to base" abandons a run and opens the hub (RUN-1, RUN-7, CRF-2,
SLV-3, CRW-1, CRW-2, CMF-8, DEV-7).

## Summary

- **Run end:** `RunWiring.abandon` ends the run through the same `_lose` path a
  destroyed ship takes (now shared with `after_level`): earlier escapes stay banked,
  the crew stays, this level's components and any miner aboard are lost, the
  statistics count a lost run, a new run is started with a new seed. A waiting
  suspended-run save is deleted.
- **One call for the row and the suite:** `RunAbandon.abandon` (`game/run_abandon.gd`)
  runs `RunWiring.abandon`, loads the new run's first level through `main.gd`'s
  `restart_level(true)` and opens the hub as a normal start does
  (`StartChoice.open_hub`): dark, ship held, launch fades in. `RunAbandon.flying_run`
  says when the row shows: the run's own level flies (not the tunnel, a single level
  from the Level entry, the hub or the flight test).
- **Menu:** new `return` kind in `xr/dev_menu.json` ("Return to base") with
  `confirm_return_text` ("Confirm: abandon run"). `DevMenuModel` hides the row without
  a run, arms it on the first press, returns `return_to_base` on the second, and
  disarms on moving up or down, closing or reopening. New `DevMenuReturn`
  (`game/dev_menu_return.gd`) closes the menu, fades out on the steady clock as the
  Restart entry does, and calls `RunAbandon.abandon` on the black frame; the hub then
  keeps the view dark.
- `main.gd` is untouched: `DevMenuWiring.attach` finds the hub as the object of the
  `hub.is_open` callable it is already given. This keeps the change clear of #1271,
  which edits the same `attach` call in `main.gd`.
- **Acceptance:** new m4 step `abandon_run` (`AcceptanceAbandonRunCheck`): run 12345's
  first level with drops on (same flight and hash as `components_bank`), the escape
  press banks `{"cell_salts": 1}`, a scratch suspended save is left, then on level 2
  the check makes `RunAbandon.abandon`, the menu row's own call, and wants the bank
  unchanged, one more lost run, the save gone and the hub open on the new run's first
  level. It closes the hub after.
