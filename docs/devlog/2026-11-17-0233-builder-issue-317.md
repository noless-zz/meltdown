## Summary

- `MineGenerator.to_level_def()`: the generator's boxes as a `LevelDef` with no robots or
  reactor, the start `START_INSET_MM` (3 m) inside the oldest open connector, facing in.
  Open connectors are kept oldest first, so that is the first module's lowest open one
  whenever the first module has one left (when every connector of the first module was
  joined, the next module's). No open connector at all gives an empty level with `error`.
- `LevelValidator` in `game/gen/` (`RefCounted`): `parse_json` reads
  `game/data/gen/validator.json` (`min_passage_ship_diameters`, 2.5, accepted 1..20);
  `validate(level, ship_radius)` returns one message per failure, each starting with the
  check (`piece`, `passage`, `start`, `reachable`) and naming the box or boxes.
  - `piece`: boxes that share volume form one piece from box 0; boxes that only touch do not.
  - `passage`: where two boxes share volume, the shared region's sides across the crossing
    axis (the axis where the boxes lie on opposite sides) must both reach
    `min_passage` = diameters x 2 x ship radius, 5 m for the default ship.
  - `start`: some box holds the start with the ship's radius to spare.
  - `reachable`: every box reachable from the start's box through openings that are wide
    enough and `LevelDef.joined` (a ship has to be held by both boxes to cross).
- `game/tests/seed_sweep.gd` runs N seeds and builds one summary line; the 1,000-seed test
  and `game/tests/validate_seeds.gd` (`--seeds`, `--first`, `--modules`; exit 1 on any
  failure) share it. `tools/validate_seeds.sh [seeds] [first]` wraps the latter for a
  nightly job.
