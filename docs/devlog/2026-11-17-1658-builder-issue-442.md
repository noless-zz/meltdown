## Summary

- `MapRoute` owns a billboarded `Label3D` (`RouteDistance`) that `draw_fitted` shows above
  the route's first point (the ship's end) whenever a route is drawn. The text is the
  level-space length of the given points in whole metres, rounded up (`84 m`), after
  snapping to millimetres so float noise from the millimetre route never adds a metre.
- The label is positioned through the fit but never scaled by it; its size comes from the
  pixel size, `distance_height_m / 32`, so it is the same in the hologram at any map scale.
- `clear` (and so `clear_route` and any empty or one-point route) hides the label.
- New optional `MapLook` keys with ranges and built-in fallbacks: `distance_color`,
  `distance_height_m` (0.003..0.03, 8 mm), `distance_offset_m` (0..0.05, 12 mm). Shipped in
  `map_look.json` at the built-in values. `map_hologram.gd` is not edited.
