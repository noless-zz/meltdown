## Issue

#1069 The profile keeps statistics: runs, escapes, deepest level, miners and components (CRW-2).

## Summary

- New `game/meta/profile_stats.gd` (`ProfileStats`): seven lifetime counters and the calls
  `record_run_start`, `record_escape(level_index, miners, banked)`, `record_loss`, `record_win`.
  `level_index` is the run's 0-based index (as in `RunState`); `deepest_level` stores it 1-based.
  A negative level or miner count, or a malformed `banked`, refuses the call and changes nothing.
- `Profile` gains an optional `stats` key and `VERSION` goes to 3, for the same reason as the
  version 2 bump. Version 1 and 2 files load with zeroed stats; missing counters read as 0;
  unknown counters or non-whole / negative values make the file unreadable, like other keys.
- `ProfileStore` needed no change.
