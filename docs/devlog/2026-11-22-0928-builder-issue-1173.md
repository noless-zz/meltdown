## Summary

- `bot_sweep_levels.gd`: `level_of(generator, robot_scale)` scales the robot plan with
  `RobotPlan.scaled(scale, placements)`, as `SeedLevel.level_of` does.
- `bot_run_sweep.gd`: level 1 is built at 1.0 and each later level at the chosen shaft's
  `risk.robot_count` (`RunState.current_risk`, which `RunWiring.level_robot_scale` reads).
  `fly_level` now takes a fourth argument, the robot scale.
- Each `MELTDOWN_BOT_RUN` line ends with `"robot_scales":[...]`, two places each. The
  summary line is unchanged.
- New `--shaft=<index>` (default 0): the shaft at that position in each offer, the last
  offered when the offer is shorter.
- `test_bot_full_run.gd` flies through the same `fly_level` with the scale. Stubs in
  `test_bot_run_sweep.gd` and `test_bot_sweep_fitted.gd` take the new argument.
  The pinned run 12345 line gained its scales (`1.00,1.30,1.10`); its outcome did not move.
- New `test_bot_sweep_robot_scale.gd`, 4 tests: scales per level, robot counts equal
  `LevelSwitch.load_level("seed:<n>:robots=<scale>")` for every level of run 12345,
  the `--shaft` pick, and option parsing.
