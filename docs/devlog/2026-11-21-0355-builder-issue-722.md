## Summary

- New `game/xr/swivel_yaw.gd` (`SwivelYaw`, `RefCounted`) and `game/xr/swivel.json`
  (`enabled` false, `dead_zone_deg` 30, `gain_per_deg` 0.03, `max_input` 1.0,
  `follow_deg_per_s` 5). Loaded and range-checked like `HitShake`; a bad file is rejected
  naming the field and stays off.
- `update(head_yaw_rad, delta)` returns a yaw stick value in -1..1 (+ nose right, like the
  stick's x) from the head's yaw against a reference: 0 inside the dead zone, then
  `gain * degrees past it`, capped at `max_input`. The reference drifts towards the body at
  the follow rate; `recentre(yaw)` sets it at once.
- `added_to(input, stick_yaw)` adds the value to a `ShipInput`'s yaw, clamped to the stick's
  full rate, so it goes through `ComfortInputFilter` like the stick does.
- No edits to `comfort_wiring.gd`, `main.gd` or `comfort_input_filter.gd`.
