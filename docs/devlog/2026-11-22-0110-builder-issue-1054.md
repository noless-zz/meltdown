## Issue

#1054: the ship a run starts with, ship file, fitted upgrades and crew benefits in one
pure step (CRF-4, CMB-1, CRW-1, CRW-3, ARC-1, ARC-4).

## Summary

- New `meta/run_start_ship.gd` (`RunStartShip`, static only): `build(ship_data, fitting,
  tree, profile, roles, notes)` returns a deep copy of the ship file with its `loadout`
  section from `Fitting.loadout` and the crew's totals applied by
  `CrewBenefits.apply_to_ship`. `ship_data` is never changed.
- A null fitting, profile or roles leaves that part out. A fitting that `Fitting.check`
  refuses against `profile.crafted` is dropped and the ship file's loadout flies; the
  reason (which names the slot) goes to `notes`. Crew problems from
  `CrewBenefits.totals` go to `notes`, prefixed `crew:`.
- An empty fitting does not touch the `loadout` key, so a ship file without one stays
  exactly as it was.
