## Summary

- `ReactorView` gains `frozen: bool` (default false). While true, `_process` returns before
  advancing the pulse, so the phase, light energy and core emission keep their last values.
  Clearing it resumes from the same phase; nothing is reset, so there is no jump.
- `advance()` itself is unchanged: `frozen` stops only the view's own clock, which is what
  the pause needs (CMF-8, PLT-7). The look file and every other behaviour are untouched.
- Setting `frozen` from the session's `paused` is #422 (lane-b); not wired here.
