## Summary

- `game/xr/thumbstick_mapping.gd`: new controls `left_stick_click` and `right_stick_click`,
  passed in the existing optional `buttons` argument (missing means released). New button
  action `afterburner` in the layout, bound like an axis, default `{"left_stick_click": 1.0}`.
  It is held when its bound controls add up to at least `BUTTON_THRESHOLD` (0.5), so it can
  also be remapped to a grip or trigger. Left-handed mode swaps it to the right stick click
  through the existing hand swap. The result goes into `ShipInput.from_floats(..., afterburner)`.
- `game/tests/test_thumbstick_mapping.gd`: `_diff` now also compares `afterburner`; four new
  tests: pressed and released (and boosting leaves the axes alone), default released with no
  buttons argument, left-handed swap, custom button and analogue controls, and a layout
  without the entry.
