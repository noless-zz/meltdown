## Summary

- The default exit radius now lives in data: `game/data/level_defaults.json`
  (`{"exit_radius": 4.0}`), as the review asked (ARC-4).
- New `LevelDefaults` in `game/core/` parses that text (one required key, metres held as
  whole mm, same range checks as `exit_radius` in a level). Core opens no files: the
  existing level loader, `LevelSwitch.load_level`, reads the file and hands the defaults to
  `LevelDef.parse_json(text, defaults)`, which gives them to the level and its reactor.
- A missing or rejected defaults file keeps the level off (test tunnel), with the reason
  printed, rather than flying a guessed default.
- `ExitRule.DEFAULT_RADIUS_M` is gone. `LevelDefaults.FALLBACK_EXIT_RADIUS_MM` remains only
  for callers that hand in no defaults: tests that parse a level string, and reactor replay
  lines without `exit_radius`. The game's level path never uses it.
- Merged `main` into the branch (no conflicts) instead of rebasing, so no force push.
