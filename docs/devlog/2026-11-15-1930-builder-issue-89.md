## Summary

- `LocalSession.new(..., tuning)` gives every ship the tuning before the first tick. Null,
  or a tuning with `error` set, flies the built-in defaults.
- `LocalSession.load_tuning(path)` reads a ship data file; a missing or rejected file prints
  `Meltdown: ship tuning <path> rejected (<reason>); flying with the built-in defaults` and
  returns null.
- `main.gd` loads `res://data/ships/default_ship.json` through it (`SHIP_TUNING_PATH`).
- Replay format version 5: an optional `tuning {...}` header line holding the ship data file
  as one line of JSON at full precision. `Replay.run()` applies it, so a replay of a tuned
  session ends at the same hash, also after a text round trip. Untuned replays write no
  tuning line; versions 1 to 4 are read as before and reject a tuning line.
- `export_presets.cfg`: `include_filter="*.json"` on all three presets, which also takes the
  `xr/layouts/*.json` files from #82 into the builds.
- Tests: `test_session_tuning.gd` (11) and one new check in `test_export_presets.gd`.
