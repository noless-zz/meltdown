## Summary

- `ShipState` gains `hold` (part ids in pickup order), `HOLD_CAPACITY = 1` and
  `hold_has_room()`. The hold joins the ship hash, tagged, only while non-empty, so runs
  without pickups hash as before.
- New `game/core/salvage_pickup.gd` (`SalvagePickup`, `PICKUP_RADIUS = 1.5` m). Each tick,
  after the projectile hits, every live ship with room takes the items its centre passed
  within `radius + PICKUP_RADIUS` of, on the segment it flew that tick (from after a
  reset, to after the wall bounce), using `Projectile.segment_entry`. Ships go in index
  order, so a tie goes to the lower index; per ship the item reached first along its path
  wins. Taken items leave `Sim.salvage` in order.
- `SimEvent.Kind.SALVAGE_COLLECTED` appended: ship = the collector, magnitude = the item's
  index before this tick's pickups, vector = where it floated. Reported before any
  `SALVAGE_DROPPED`, which stays the tick's last event.
- `sim.gd` grows by four lines (now 316). The pickup lives in its own file rather than in
  `sim.gd` because of the 300-line guideline; the file list in the issue did not name it.
