## Summary

- `Sim.set_parts(parts: Dictionary) -> String`: the part catalogue, part id to resolved
  `WeaponDef`. Only before the first tick; ids follow the weapon id rule, values must be
  parsed weapons; a refused catalogue changes nothing. Stored privately as a copy and read
  through `part(id)` and `part_ids()` (sorted), so it is read-only once set.
- `Sim.state_hash()` adds the catalogue (ids sorted, each id and its weapon's values hash)
  only while it is non-empty, so every pinned hash stands.
- Replay format 10: one `part <id> <json>` line per part, sorted by id, after the robot
  lines. `Replay.run` sets the same catalogue before tick 0 and fails with `run_error` if
  `set_parts` refuses it. Versions 1 to 9 still read; a part line in them is an error.
- The part lines live in a new `game/core/replay_part_lines.gd` (`ReplayPartLines`), since
  `replay_lines.gd` is at 273 lines. `sim.gd` is now 290 lines, `replay.gd` 261.
