Scheduled Builder run in lane-a. No open pull request closed a lane-a issue, so there was

## Summary

- `tools/write_build_info.sh <commit> <unix-time> <output>`: checks for 40 hex characters
  (lower-cased) and a whole number of seconds, then writes a plain `Resource` with
  `metadata/commit` and `metadata/built_unix`. It writes to a temporary file and renames,
  so a refused call leaves nothing behind.
- `tools/build.sh` calls it before the import and export of every target, with `GITHUB_SHA`
  or `git rev-parse HEAD` and `date +%s`, into `game/meta/build_info.tres`, which is in
  `.gitignore`. `export_presets.cfg` is untouched: `all_resources` already takes `.tres`.
- `game/meta/build_info.gd` (`BuildInfo`): `load_from(path)`, `commit`, `built_unix`,
  `short_commit()`, `describe()` (`"0123456, built 2026-01-15 10:00 UTC"`). It loads
  through `ResourceLoader`, because an export may convert the text resource to binary and
  remap it. A missing file or a wrong type or value reads as `"unknown"` and 0.
- `tools/test_write_build_info.sh` (10 checks): a valid call must write byte for byte the
  committed fixture `game/tests/fixtures/build_info_valid.tres`, which the unit tests load
  through `BuildInfo`; bad commits and times exit non-zero and write nothing.
- `game/tests/test_build_info.gd` (6 tests) with a valid and a malformed fixture.
