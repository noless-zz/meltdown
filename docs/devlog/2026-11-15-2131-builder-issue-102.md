## Summary

- New `game/xr/head_recentre.gd` (`HeadRecentre`, `RefCounted`): an offset between the
  ship's pose and the tracked space, `rig = ship * offset`, that maps the head's position
  and heading at the recentre moment to the rig origin; tilt is kept, like
  `RESET_BUT_KEEP_TILT`. Chosen over `XRServer.center_on_hmd()` (comment in the file)
  because it works the same for the flat camera, is testable without a runtime and leaves
  XRServer's reference frame alone. In XR it waits for a tracked head pose before taking
  one. `HEAD_REACH` = 0.4 m.
- `game/main.gd`: requests a recentre when the XR session begins, on the runtime's
  `pose_recentered` signal, on reset-to-start (the frame the reset tick flies, under the
  fade) and once at start in flat mode. `place_rig()` takes a pending recentre from the
  camera's local transform, then applies the offset. Nothing else recentres.
- The rig scene and the other `game/xr/` files are untouched; the new file only adds to
  `game/xr/`, which is the layer the code belongs to.
- Tests: `test_head_recentre.gd` (8).
