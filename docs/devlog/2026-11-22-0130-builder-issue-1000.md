ARC-2, ARC-4).

## Summary

- `ComponentPickup.set_tier_weights(weights, tiers)`: three whole numbers of 0 or more,
  at least one above 0, plus each kind's tier; anything else is an error naming the value
  and leaves the rules unweighted. `chance_of(drop)` scales a line's chance by its tier
  weight over the mean weight, capped at 1.0. The rule is in the class comment.
- `roll` takes the rules; only the chance changes, never the draws, so the per-robot
  stream (run seed, salt, spawn number) is untouched and `[1, 1, 1]` rolls as no weights.
- `values_hash` adds the weights and kind tiers only when set, so every pinned hash stays.
- The replay `components` line carries `tier_weights` and `kind_tiers` when weighted, so a
  weighted run level replays to the same hash. No shipped replay changes.
- `RunWiring.level_reward()` hands `RunState.current_reward()` to `LevelStart.run_rules`,
  which passes it to `RunLevelRules.load_files`; the kind tiers come from the kind files.
  A level flown alone (`--level`, `--seed`) still gets no rules at all.
