## Issue

#792 (M1, CMF-7, CMF-1, ARC-3): the status panel shows when swivel-chair mode is on.
Lowest-numbered ready lane-c issue without an open pull request.

## Summary

- `status_panel_look.json` gains `preset_swivel_text` ("Swivel"); `StatusPanelLook`
  accepts it as an optional text key with the same fallback and rejects an empty or
  non-text value.
- `StatusPanelPresetRow` takes the tag from the look (an optional `look` argument, the
  shared look by default) and shows "Preset <n> <name> <tag>" while `show_swivel(true)`;
  `text_for` builds the words. Text only: the label never moves or animates.
- `RigViews.show_swivel(panel, comfort)` hands the panel the active preset's
  `swivel_enabled`; it is called from `place_guarded`, the one per-frame call that already
  sees both the comfort wiring and the panel, so `main.gd` is untouched. The tag therefore
  changes only when the preset does.
- `StatusPanel._preset_row` became `preset_row` so `RigViews` can reach it without a new
  method; the panel file stays at 295 lines (its test wants under 300).

## Test results
