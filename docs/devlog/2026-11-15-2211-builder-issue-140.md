## Summary

- New `game/tests/script_error_logger.gd`: a `Logger` registered with `OS.add_logger()`
  that collects `ERROR_TYPE_SCRIPT` errors only. Warnings and engine errors (`push_error`,
  rejected files) are not counted, since several tests feed bad data on purpose. Captures
  nest and an error goes to the innermost one, so the runner's own test does not fail on
  the fixtures' deliberate errors. The logger is removed when the last capture closes.
- New `game/tests/runner_core.gd`: the per-file logic taken out of `run_tests.gd`. A test
  fails with `FAIL <file>::<method> - script error: <message> (<file>:<line> in <fn>())`
  when a script error was raised while it ran, whatever it returned. A file that does not
  load is still `FAIL <file> - could not load script`.
- `run_tests.gd` now calls `RunnerCore.run_file()` and prints its lines; the output
  format and exit codes are unchanged otherwise.
- Fixtures in `game/tests/fixtures/runner/` (skipped by the normal run): a call on null, an
  index past the end, an error inside a helper (Godot aborts only the helper and the test
  returns `""`), a file that does not parse, and a file with two passing tests (one pushes
  a warning) and one that returns a message.
- `test_run_tests_runner.gd` (7 tests) runs them through `RunnerCore`.
- Exposed by the change: `test_reset_hold.gd::test_the_overlay_shows_the_fade_under_the_camera`
  read `overlay.mesh` after `main.free()`. Fixed by reading it first. No other test was
  silently erroring.
