## Cause

The Planner was right: the step flew the alarm replay with the alarm off. The acceptance
runner builds its session through `ReplayInputSource.new_session()`, which copies each
replay line onto the live session by hand. When the alarm line arrived (#1342, replay
version 20) it was added to `Replay.run` via `ReplayRulesLine.apply`, but not to
`ReplayInputSource`, which copied component drops and miner rescue and stopped there.
2519309766 is exactly m3's `bot_g2_escape` hash, the same flight without the alarm.
The music check still heard tension because it does not read the sim's alarm.
