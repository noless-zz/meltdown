## Summary

- New `game/gen/debris_escape.gd` (`DebrisEscape`): the `debris_escape` check. It flies the
  escape at `escape_speed_mps` from the reactor to the exit with every solid entry fallen that
  the route guard would let fall (held entries stay up, fire is passable) and requires it to fit
  `escape_margin` of the countdown for the clear path. The message names the entries whose
  absence alone shortens the route.
- The guard's held entries are worked out on `OpeningGraph` (new, `game/gen/opening_graph.gd`):
  the level's openings are found once, each entry re-tests only the openings it is near, and a
  box search checks reachability. `KnownRoute` runs only when fallen debris blocks an opening.
  A test compares the held entries with `DebrisRouteGuard` itself on the hand-built level and
  seeds 0..199.
- `LevelValidator.CHECKS` gains `debris_escape` between `escape` and `robots`; it runs only when
  the clear escape passes. `SeedSweep` and the nightly run count it by name with no change to
  lane-b files.
- `DebrisPlan.place` calls `DebrisEscape.trim` after the doors. Each round drops the
  highest-numbered entry that lengthens the route (doors before spheres, later draws first)
  until the check passes. The speed and margin come from `escape_validator`; `SeedLevel` passes
  in the validator it read from `validator.json`, and the defaults match that file.
- `debris_plan.gd` was split first: parsing moved to `debris_plan_file.gd` (`DebrisPlanFile`),
  leaving 254 lines.

## Test results

- Godot 4.7.2-stable in the run's scratch space, `--import` then `run_tests.gd`: 1416 tests.
  The full run had one failure, `test_a_too_slow_clear_escape_drops_nothing`, because it loaded
  `debris_escape.gd` before the fix that test covers was saved. Run again after the fix,
  `test_debris_escape.gd` passes 10 of 10.
- Shipped data, seeds 0..999: 0 entries dropped. Only 28 seeds have a longer route once debris
  falls, and the worst takes 52% of the countdown against the 80% margin. So no `output_hash`,
  reactor, robot, debris or pin moves.
- With a 0.4 margin, seeds 0..299: 3 entries dropped on 3 seeds, and every level passes.
- Level validator sweep (1..1000): the first push used `KnownRoute` for every guard step. It
  took 29.1 s in CI against 13.9 s on `main`, failing the 20 s limit. With `OpeningGraph` it
  takes 16.5 s on this machine against 14.4 s on `main`. The CI figure is in the pull request.
