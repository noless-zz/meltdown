## Summary

- `xr/dev_menu.json` and `DevMenuSpec`: the entries and their order (`corner`, `level`,
  `restart`, `close`, each at most once, with a label), the corner names offered, and the words
  for the tunnel, seed and random choices. A missing or rejected file gives the built-in four
  entries, with the problem named.
- `DevMenuModel`: input as named actions held this frame (`menu_up`, `menu_down`, `menu_left`,
  `menu_right`, `menu_confirm`, and `menu_seed_down`, `menu_seed_up`, `menu_seed_down_far`,
  `menu_seed_up_far` for ±1 and ±10), each counted only on the frame it is pressed. The level
  choices are the tunnel, every level file `LevelSwitch.path_for` accepts, Seed and Random. The
  seed stays within 0 and 18 nines. Confirm returns `corner:<name>`, `level:<source>` (`""`, a
  level path, `seed:<n>` or `random`), `restart` or `close`.
- `DevMenu` (`Node3D`): one centred line per entry, 1 m ahead, the selected one marked and
  amber; no fade, no motion, no depth test. Closed, it ignores input.
