## Summary

- `game/data/run/run.json`: `min_levels` 3, `max_levels` 5, `seed_salt` 2654435769 (odd).
- `game/core/run_plan.gd` (`RunPlan`): `build(run_seed, text)` parses the file (errors name
  the key) and gives the level count and each level's seed and depth. The mix is documented
  in the class: fold the 64-bit run seed to 32 bits, count from `fmix32(base)`, level `i`
  from `fmix32(base + (i + 1) * seed_salt)`. Only masked 32-bit arithmetic, with the
  multiply in 16-bit halves, so no step depends on integer overflow. `fmix32` is a
  bijection and the salt is odd, so one run's levels never share a seed.
- `game/core/run_state.gd` (`RunState`): current level index, `advance()` after an escape
  (wins after the last level), `lose()` (RUN-7), and a state hash.
- Nothing in the game uses either class yet, so every replay and suite hash is unchanged.
