# 2026-11-15 Builder, issue #40 (lane-a)

Scheduled Builder run in lane-a. No open pull request closes a lane-a issue, so the run
took the only `ready` lane-a issue: #40, wall bounce with minor damage inside a
box-shaped tunnel (FLT-3, ARC-1, ARC-2, ARC-4).

## Summary

- New `game/core/box_bounds.gd` (`BoxBounds`): min and max corner in metres.
  `contain(ship)` mirrors any overshoot back inside, reflects the velocity component into
  each wall crossed, scaled by the ship's restitution, keeps tangential components, and
  applies damage once per tick from the length of the into-wall components (a corner hit
  is one impact). A ship far past the box is clamped, never pushed out the other side.
- `ShipState`: `hull` / `max_hull` (100), `radius` (1 m), `wall_restitution` (0.5,
  raised to at least `MIN_WALL_RESTITUTION` 0.05 so a bounce never stops the ship dead),
  `wall_damage_per_speed` (0.5 hull per m/s), `wall_damage_min_speed` (4 m/s). Head-on at
  20 m/s costs 10 hull. The ship radius lives on the ship, not the box, because it is a
  ship property a later part file sets (ARC-4).
- `hull` is in `state_hash()` once it differs from `max_hull`, so `basic_flight.replay`
  and every other wall-free run keep their hashes.
- `Sim` takes an optional `BoxBounds` (`bounds`); without one nothing changes.
- Replay format version 3: an optional `box` header line with the corners in whole
  millimetres. Versions 1 and 2 still load; a box line in them is rejected.
- New `game/tests/replays/wall_hit.replay` (300 ticks, hits the far and side walls).
