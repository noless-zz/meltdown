## Summary

- New `game/meta/fitting_store.gd` (`FittingStore`) at `user://meltdown_fitting.json`
  (path argument for tests):
  - `save(fitting)` writes through `SafeFileWrite`, as `ProfileStore` does.
  - `load_fitting()`: a missing file gives an empty fitting quietly; a corrupt file gives
    an empty fitting, one log line, and stays on disk untouched; a too-new file does the
    same and also locks the store against saving, as `ProfileStore` does.
  - `valid_for(fitting, tree, crafted, ship_data)` returns a copy without the slots
    `Fitting.check` refuses, one log line each (optional `notes` list for tests). Slots
    are judged in slot order, so of two slots holding one upgrade the first stays.
- Choice the issue left open: `Fitting` has no version and refuses unknown keys, so the
  file holds `{"version": 1, "fitting": {...}}`. The version is what lets this build
  recognise a newer file and leave it alone. `fitting.gd` is unchanged.
