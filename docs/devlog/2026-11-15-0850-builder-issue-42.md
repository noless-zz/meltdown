# 2026-11-15 Builder, issue #42 (lane-c)

Scheduled Builder run in lane-c. No open pull request closes a lane-c issue, so the run
took the lowest-numbered `ready` lane-c issue in M1: #42, thumbsticks-only control scheme
as a tested input mapping (PLT-5, FLT-1, ARC-3).

## Summary

- New `game/xr/thumbstick_mapping.gd` (`ThumbstickMapping`, `RefCounted`). It takes two
  stick vectors, two triggers, two grips and the four face buttons as plain values and
  returns a `ShipInput` through `ShipInput.from_floats`. It reads no device.
- Default right-handed layout as the issue lists it, documented in the class. Turn rates
  are named constants: pitch and yaw PI/2 rad/s, roll 0.75 PI rad/s.
- Radial dead zone `STICK_DEAD_ZONE` = 0.15, rescaled so full deflection gives 1.
- `left_handed` swaps every `left_*` control with its `right_*` twin, buttons included.
- `layout` is a dictionary `axis -> {control: weight}`, defaulting to
  `default_layout()`; the settings menu can replace it.
- `invert_pitch` flips only pitch. Without it, pushing the right stick away raises the nose.
- New `game/tests/test_thumbstick_mapping.gd`, nine tests. Both new scripts are committed
  with their `.gd.uid` files.

## Test results

Godot 4.7.2-stable, run locally exactly as CI does: 61 tests, 0 failed.

## Open questions

- Left-handed mode is a literal swap of the hands, so the right grip rolls left and the
  left trigger moves up. Whether triggers and grips should instead keep their side is a
  headset question for the owner.
- Default pitch direction (stick away = nose up) and the turn rates are guesses to be
  tuned in the headset.
