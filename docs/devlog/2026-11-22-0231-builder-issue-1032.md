## Issue

#1032: escaping adds the level's rescued miners to the crew; a lost ship adds nobody
(CRW-1, SLV-3, RUN-7, CRF-2, ARC-2, MP-2).

## Summary

- `RunWiring.after_level` and `escape_for_choice` take the level's rescued count
  (default 0). On an escape, `_bank` banks the components, then calls
  `CrewRoster.add_rescued(profile, roles, run_seed, escaped level index, count)`, and
  saves the profile once if either changed. A loss calls neither.
- `RunWiring.roles` is read from `data/crew/roles.json` at start (`use_roles`); a
  rejected file logs one line and escapes then add no crew. Any other refusal logs one
  line and sets `crew_error`; the run never stops for it.
- `RunWiring.rescued_in(sim)` reads `MinerRescue.rescued` (0 without rescue).
  `after_session` passes it, and `EscapeEndWiring` passes it through
  `ShaftChoiceWiring.open` to `escape_for_choice`, so both escape paths carry it.
