## Issue

#791 (M1, CMF-7, CMF-1, CMF-6, CMF-8, ARC-3, MP-2): swivel-chair yaw turns the ship when the
preset switches it on. Lowest ready lane-c issue in M1 (#792 waits on it).

## Summary

- `HeadRecentre` gains a `recentred(head)` signal, sent from `apply`, so every pose it takes
  (session start, runtime recentre, reset-to-start, restart) reaches the swivel. No other change.
- New `game/swivel_wiring.gd` (`SwivelWiring`): holds the active preset's `SwivelYaw`, reads
  the head heading from the rig camera (tracked space), recentres on `recentred`, and recentres
  to the current head heading when a preset change turns the swivel on. `added(input)` returns
  `input` itself when off or when an XR head is untracked, else `SwivelYaw.added_to`. The
  follow rate uses a steady clock, each step capped at 0.25 s.
- `ComfortWiring` owns it: `set_preset` hands it the preset, `hand_input` filters
  `swivel.added(input)` so preset 1 snaps and preset 2 caps apply, and `attach_cockpit_frame`
  takes the `HeadRecentre` to attach it. `main.gd` changes one line in place (still 300 lines).
