  public API is unchanged.

  no `name` field, so a level is named by its file name upper-cased.

  was already there. A rejected level file now clears `level_start.source`, so the panel says
  "Test tunnel" when the tunnel is what flies; a restart already fell back to the tunnel. Still
  300 lines.
