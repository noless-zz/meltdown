## Summary

- `level_wall.gdshader`: new uniforms `tint_by_kind`, `floor_tint`, `ceiling_tint`. With
  `tint_by_kind` set, the base colour is the floor, wall (`tint`) or ceiling tint, picked
  with the `kind` vector the shader already worked out from the normal for the plating
  (same 45 degree rule as `LevelLook.surface_class`). Off by default, so the bevels and
  the test tunnel, which use one tint, draw as before.
- `LevelViewMeshes.kind_material(look)`: `LevelLook.wall_material` in the wall tint plus
  the floor and ceiling tints from `level_look.json` (ARC-4).
- `LevelView` draws each box's walls and frames in one surface with that material; the
  bevels keep their own surface. A box now costs 2 draw calls instead of up to 4.
- `wall_depth_shown` now fails a box whose walls take more than one surface.
