# 2026-11-17 Builder, issue #328 (lane-a)

Scheduled Builder run in lane-a. No open pull request closes a lane-a issue (#230 is
lane-b), so nothing to fix. The `ready` lane-a issues were #328 and #337, both in M3; #328
is the lower. Its prerequisite #310 is merged (#333). Named in Israel time (UTC+2).

## Summary

- Box handling split out first, with no behaviour change: new `game/core/replay_box_line.gd`
  (`ReplayBoxLine`) holds the box line's text and parsing (moved from `ReplayLines`) and
  turns the corners into a `BoxBounds` or `BoxUnion` (moved from `Replay._box` and
  `walls`). `Replay.set_box`, `add_box`, `set_boxes`, `bounds` and `walls` keep their
  signatures. The pinned text of `test_replay_lines.gd` is unchanged except the version.
- Replay format 14: optional `start <ship> <x> <y> <z> <fx> <fy> <fz>`, at most one per
  ship, written after the reactor line. Position in whole millimetres; facing as a unit
  vector times 1000, rounded, like robot spawn facings. New `game/core/replay_start_line.gd`
  (`ReplayStartLine`) writes, parses and applies it.
- `Replay.set_start_pose(ship_index, position, facing) -> bool` (false for an index outside
  the ships or a zero facing). `run()` calls `Sim.set_start_pose` for each ship with a line
  right after creating the sim. The orientation comes from the new
  `RobotSpawn.facing_basis`, which `RobotSpawn.orientation` now also uses (same up rule).
- Without a line, or in versions 1 to 13, ships start at the origin facing -z as before. A
  `start` line in an older version fails with "line N: a start line needs format version 14
  or later". Other refusals: index outside the ships, zero facing, wrong word count,
  non-integers, a second line for the same ship, a line before `ships`, a position beyond
  10 km.
- `replay.gd` is now 291 lines (was 272 before this change, 308 when the issue was written).

## Test results

- Godot 4.7.2-stable in the run's scratch space; `--import` then `run_tests.gd` exactly as
  CI: 1029 tests, 0 failed (8 new in `game/tests/test_replay_start.gd`).
- A ship starting at (3, -2, 10) m facing +x, with a reset to start half way, replays from

  plain `Sim` all end on the same hash; committed replays and pinned hashes still pass.
