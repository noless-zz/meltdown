# 2026-11-15 Builder, issue #87 (lane-a)

Scheduled Builder run in lane-a. No open pull request closed a lane-a issue (#101 is
lane-b), so there was nothing to fix. The run took the only `ready` lane-a issue in M1:
#87, range checks on ship tuning values from the data file (ARC-4, FLT-1, FLT-2, FLT-3).

## Summary

- `ShipTuning.RANGES`: an inclusive [minimum, maximum] for every key. A bound may name
  another key: `afterburner_max_speed` is `max_speed`..300 and `afterburner_restart_energy`
  is 0..`max_energy`.
- `parse_json` checks ranges after every value is read (some bounds are other keys); the
  first value out of range returns the defaults with an error such as
  `key "radius" is 0, must be at least 0.1`.
- Each field's doc comment now gives its range next to its unit, with the reason where the
  bound is not obvious (damping above the tick rate, zero drain or recharge, a restart
  threshold above the pool).
- `game/tests/test_ship_tuning_ranges.gd`: 12 tests. Every key has a range; defaults and the
  shipped file pass; a value just below each minimum and just above each maximum is rejected
  with its key named; values exactly at each bound are accepted; the issue's examples
  (negative speeds, `max_speed` above `afterburner_max_speed`, restitution outside 0..1,
  radius 0 or less) are rejected; a rejected file keeps the defaults.

Ranges chosen: max_speed 1..200, acceleration 1..1000, damping 0..60, max_energy 1..1000,
afterburner_acceleration 1..2000, afterburner_drain 0.1..1000, energy_recharge 0.1..1000,
max_hull 1..10000, radius 0.1..10, wall_restitution 0..1, wall_damage_per_speed 0..100,
wall_damage_min_speed 0..300.

## Test results

Godot 4.7.2-stable, run locally exactly as CI does: 236 tests, 0 failed. With the range
check in `parse_json` disabled, 8 of the new tests fail.

## Open questions

- The upper limits are generous sanity bounds, not balance values; tighten them once
  headset tuning shows the useful band.
- `afterburner_acceleration` is not required to be at least `acceleration`; the issue did
  not ask for it. Add it if a weaker afterburner should be impossible.
