## Summary

- `game/xr/render_model_report.gd` (`RenderModelReport`, a `Node`): after the OpenXR session
  begins it prints `MELTDOWN_RENDER_MODELS` + JSON with the runtime name and version, whether
  `xr/openxr/extensions/render_model` is on, and whether the runtime supports it
  (`OpenXRRenderModelExtension.is_active()`). A second line gives the number of runtime
  models and their top-level paths, on the first `render_model_added`, after 10 s, or at exit.
- Godot 4.7.2 does not expose the runtime's OpenXR extension list to scripts, so the first
  line carries `"extensions":null` and `"extensions_exposed":false`.
- `xr_rig.gd` adds the report in `build()`. Logging only; the generic shape stays.
