## Summary

- `LevelSwitch.requested_source` takes an optional `pick_seed` callable. A seed value of exactly
  `random` (argument or intent extra, after trimming) is replaced by the picked seed, printed as
  `Meltdown: flying random seed <n>`, and returned as `seed:<n>`, the same source `--seed=<n>`
  gives, so the session, level and replay seed are built exactly as for that number.
- `LevelSwitch.random_seed` draws 1..999,999,999 from a freshly randomized
  `RandomNumberGenerator`. It is the only unseeded randomness and lives beside `main.gd`, not in
  `core/` or `gen/` (ARC-1).
- Any other non-digit value (`Random`, `rand`, `random7`, ...) is still rejected, and `--level`
  still wins.
