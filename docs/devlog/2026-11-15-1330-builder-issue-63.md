# 2026-11-15 Builder, issue #63 (lane-b)

Scheduled Builder run in lane-b. The open pull requests (#86, #95) do not close a lane-b
issue, so there was nothing in lane-b to fix. The run took the lowest-numbered `ready`

(FLT-3, MP-2, CMF-8). Both prerequisites (#40, #60) are closed.

## Summary

- `game/view/test_tunnel.gd`: now `class_name TestTunnel`, with a static
  `interior_box(offset)` that returns the inside of the walls, floor and ceiling as a
  `BoxBounds`, shifted by where the tunnel node sits.
- `game/net/local_session.gd`: optional `bounds` argument. The walls go into the replay's
  box line first and the `Sim` takes them back from the replay, so live play and its
  replay meet exactly the same (millimetre-rounded) walls.
- `game/main.gd`: the session flies inside `TestTunnel.interior_box(TUNNEL_OFFSET)`, and
  `place_tunnel()` (called in `_ready`) moves the drawn tunnel to the same offset.
  `TUNNEL_OFFSET` is 1 m down: the ship keeps starting at the simulation origin (so replays
  need no start position), and its 1 m collision sphere starts touching the floor instead
  of inside it, which would make the first tick jolt the ship upwards.
- `game/tests/test_tunnel_bounds.gd`: 5 tests.

## Test results

Godot 4.7.2-stable, run locally exactly as CI does: 183 tests, 0 failed. With the session
built without walls, 2 of the new tests fail; with `TUNNEL_OFFSET` at zero, 5 tests fail
(the ship starts outside the walls).

## Open questions

  about 2.6 m up in a 4 m tunnel (seated about 2.2 m). Does that feel right, or should the
