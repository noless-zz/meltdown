## Summary

- `Profile` gains `crew`, a list of `{id, role}` saved under a new `crew` key. A file
  without the key loads with an empty crew. Shape errors (not an object, missing or empty
  `id`/`role`, unknown key, duplicate id) reject the file and name the entry.
- `Profile.VERSION` raised from 1 to 2. Reading does not need it (crew is optional), but a
  version 1 build refuses unknown keys: without the bump it would call a profile with crew
  unreadable, start empty and save over it. With the bump it sees a newer file and locks.
  A loaded version 1 file is written back as version 2.
- New `game/meta/crew_roster.gd` (`CrewRoster`): `add_rescued(profile, roles, run_seed,
  level_index, count)` appends seeded members with ids `crew-<n>`, skipping ids already
  taken; `check(profile, roles)` names an entry whose role is unknown; `miner_seed` mixes
  run seed, level index, miner number and a salt. Refusals leave the profile unchanged.
- `RunBanking` is untouched; the class comment says the escape path (lane-b, #1032) calls it.
