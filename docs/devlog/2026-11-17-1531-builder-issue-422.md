## Summary

- `SessionSnapshots.debris(source)` returns a Dictionary of plain parallel arrays under the
  `DEBRIS_*` keys: positions and radii in metres, solid, held (skipped), and seconds until
  solid. Every array is empty for null. Seconds until solid are INF while the reactor lives
  (the debris clock has not started) and for a held entry, and zero once an entry is solid.
- `MeltdownWiring.update` builds that snapshot every frame and creates a `DebrisView` under
  the world (main) node when it is non-empty, feeds it with `show_debris`, and removes it
  when empty. The view is created from `update` rather than only in `attach`, because
  debris can be given to the simulation after `_ready` but before the first tick
  (`Sim.set_debris`), which is how the tests (and later #439) do it.
- `MeltdownWiring.update` sets `reactor_view.frozen` from `session.paused`.
- `main.gd` untouched (298 lines); `meltdown_wiring.gd` is 94 lines, so no split.
