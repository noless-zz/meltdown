## Summary

- New `game/tests/seed_level_cache.gd`: generators and built levels by seed, made once
  for every sweep. Two variants: the shipped level (`SeedLevel.level_of`, as `--seed`
  flies it) and the same level without the `fires` section. It times its generating and
  building, keeps each generator's `output_hash` from before any build, and keeps a
  fingerprint of each level as built so a later test can show no sweep changed one.
- `SeedSweep.shared_generators` now hands out the cache's generators. `SeedSweep.run`
  reads a shared generator and level when one exists for the shipped files, and never
  fills the cache, so the nightly 10,000-seed run keeps nothing.
- The fires, debris, doors, debris-escape (shipped margin) and fall-limit sweeps take their
  generator and level from the cache; each keeps its own checks. Levels each sweep needs
  only for itself (spheres only, untrimmed, no debris, the debris test's fresh rebuild)
  are still built there.
- The fires sweep times its checks against 30 s and holds the cache's total generating and
  building to the same limit, so a slow generator or level build still fails.
- New `test_seed_level_cache.gd`: shared levels equal fresh builds (both variants), are
  built once, leave the generator's hash as generated, give `SeedSweep.run` the same
  verdicts, and none of the 2,000 shared levels changed after the sweeps ran.
