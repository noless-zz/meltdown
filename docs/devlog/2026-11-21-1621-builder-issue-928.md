## Summary

- `game/meta/profile.gd` (`Profile`): `version`, `banked` (component id to count, zero
  counts dropped) and `crafted` (upgrade ids). `bank` and `spend` refuse the whole call,
  changing nothing, on a malformed count or a count that would go negative. `to_json`
  writes sorted keys so an unchanged profile writes the same bytes. `parse_json` never
  crashes: a rejected text gives an empty profile and `error`; a newer `version` is
  checked first (a newer build may add keys) and sets `too_new`.
- `game/meta/profile_store.gd` (`ProfileStore`): `user://meltdown_profile.json`. A save
  writes `<path>.tmp`, reads it back, then renames it over the profile. A missing or
  unreadable file loads as an empty profile with `message`. A newer-version file locks
  the store: saves are refused and the file is left byte for byte. A leftover `.tmp` from
  a killed save is ignored and replaced by the next save. `stop_before_rename` is the
  test seam for the kill.
