## Summary

- `LevelStart.session_for` records the run's crew totals (`CrewBenefits.totals`) for the
  session it builds for the run's level; `crew_totals_for(session)` hands a copy, and
  `{}` for any other session (`--seed`, `--level`, the tunnel, an older session).
- `main.gd` hands that callable to `map.attach` on the existing line (still 300 lines).
- `MapWiring`: with `map_reveal` >= 1, every box is drawn from the first frame; the
  boxes not flown yet (`ExploredBoxes.unexplored`, new) go to a second surface of the
  same line mesh. New `begin(session)` is the first frame's work, and `start_boxes`
  counts what it drew. Without the benefit the map builds exactly as before.
- `MapShapes.outline` takes the revealed segments too and fits both together, so a
  revealed map keeps its size as the pilot explores. The dim surface is unshaded and
  see-through in `unexplored_color` at `unexplored_alpha`, new optional keys in
  `xr/map_look.json` (ARC-4). `MapHologram.segment_count` counts the explored surface by
  name; `revealed_segment_count` is new.
- Acceptance: new lane-a check file `acceptance/checks/map_reveal_check.gd`, listed on
  m6 `pickup_look` before the moving `crew_joins`.
