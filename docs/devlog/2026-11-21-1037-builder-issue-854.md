## Issue

#854 (M1, PLT-5, ARC-4, FLT-1, DEV-6): the gripped stick and throttle's feel values come
from a data file.

## Summary

- New `game/xr/layouts/gripped_default.json`: grip hold threshold, stick tilt and twist
  dead zones and full deflection in degrees, throttle dead zone and full travel in
  metres, with the old constants' values.
- New `game/xr/gripped_feel_spec.gd` (`GrippedFeelSpec`): checks every key is present, a
  number (not a bool), in range, each dead zone below its full deflection, and no unknown
  key. Any rejected value drops the whole file for the built-in values. `shipped()` reads
  the file once, so a rejected file is printed once with its path and field, the way a
  rejected ship tuning file is.
- `GrippedStickMapping` reads `feel` (the shipped spec) instead of its constants. The
  constants stay as the built-in values, now taken from the spec's defaults, because
  `gripped_controls_model.gd` sizes the visible stick and throttle from them.
- `GrippedSampler` asks the mapping whether a grip holds, so grabbing follows the file's
  threshold too. Buttons, left-handed mode and the afterburner are unchanged.
