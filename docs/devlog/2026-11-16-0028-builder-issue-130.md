## Summary

The Reviewer showed that the release-build guard in the real entry point was untested:
`run_if_requested()` repeated the rule with its own `OS.is_debug_build()` check, while the
tested `should_run()` was called by nothing in the game.

- `game/meta/installer_probe.gd`: `run_if_requested()` now only gathers its inputs and calls
  `_run_if_requested(is_debug_build, user_args, runtime)`, which returns `""` before reading
  the intent extra or touching the runtime when `is_debug_build` is false. `should_run()` is
  removed, so no production-looking helper is test-only.
- `game/tests/test_installer_probe.gd`: `test_never_runs_in_a_release_build` calls
  `_run_if_requested(false, ["--installer-probe"], null)` and expects `""`; new
  `test_runs_in_a_debug_build_when_asked` checks the debug path reaches `unsupported` off
  Android and stays silent when not asked.
