## Summary

- `data/levels/stress_level.json`: an ordinary level, flown with `--level=stress`. Its walls
  are `room_four_way`, the largest module by volume (30 x 16 x 30 m). 20 robots of all six
  types, and a reactor straight ahead of the start with a 16-point hull and a 120 s meltdown.
  The exit radius is 1 m.
- `data/levels/stress_scene.json`: what a level file has no key for. It holds the seed, the
  module name, the ship file, the starts of ships 1 to 3, one scripted input per ship, and
  8 lights.
- `data/levels/stress_ship.json`: the default ship with a 10,000-point hull, a 10,000-point
  shield and a shield recharge of 100. With the default ship, 20 robots destroyed all four
  ships within 5 s, which ends the scene before anything is measured.
- `acceptance/stress_inputs.gd` (`StressInputs`): one ship's script as segments (`ticks`,
  `thrust`, `turn`, `fire`), looping from `loop_from`. Every field is checked and a bad one
  is named.
- `acceptance/stress_scene.gd` (`StressScene`): reads the scene file and builds it as a
  `Replay`. It starts from the session `--level=stress` builds, adds the ship count and the
  extra ships' starts, and adds every ship's input for each tick. `core/` is unchanged, and a
  test checks that no core file mentions it (ARC-4).
- The meltdown is started by flying, not by code. Ship 0 flies forward out of the exit
  sphere, firing, and the reactor dies within the first second.
- `view/scene_lights.gd` (`SceneLights`): 8 shadowless `OmniLight3D`s placed under the level
  drawing. GFX-4 allows shadows from the headlight only. `LevelStart.level_session` places
  them for the stress level only. A new level rebuilds the drawing and removes them, and the
  tunnel frees the drawing.
- Step `stress_scene` in `suites/m6/perf.json` flies `acceptance/replays/stress_scene.replay`,
  which is ship 0's script for 5,600 ticks (2 s settle plus 60 s measurement at 90 Hz).
  The step's checks:
  - `final_hash`: 1601082185.
  - `stress_scene`: a new check in `acceptance/checks/stress_scene_check.gd`. It needs 20
    robots, 4 ships in the file, 8 lights listed and drawn, and the meltdown still counting
    down at the end.
  - `frame_budget`: measures 60 s and is skipped away from the headset.
  - `no_script_errors`.
