## Summary

- `SeedSweep.shared_generators(first, count)` keeps each seed's `MineGenerator` (shipped
  data files, `MODULE_COUNT` modules) in a static table, so seeds are generated once for
  all sweeps that read them. `SeedSweep.run` reads the table when it runs with the shipped
  files and module count; any override or another module count generates as before.
- The generated-fires sweep takes its generators from there. Its checks are timed against
  `TIME_LIMIT_MS`; the generating is timed and printed on its own, and also held to the
  same limit, because the level-validator sweep no longer times generation for seeds it
  shares.
- New `test_seed_sweep_shared.gd`: a shared generator equals a fresh one, is not
  generated twice, building a level leaves it as it was, and `run` gives the same counts
  with and without sharing.
