# 2026-11-15 Builder, issue #43 (lane-c)

Scheduled Builder run in lane-c. No open pull request closes a lane-c issue (#46 is
lane-a), so the run took the only `ready` lane-c issue: #43, comfort presets as data files
matching the comfort table (CMF-1, CMF-2, ARC-3, ARC-4, ARC-5).

## Summary

- New `game/xr/comfort_preset.gd` (`ComfortPreset`, `Resource`): one exported, typed field
  per table row, with units in comments. Enums for yaw, pitch and roll modes, vignette
  trigger and cockpit frame. `NO_LIMIT` (0) marks a rate or angle without a limit.
  Two read-only helpers, `has_smooth_rotation()` (CMF-3) and `has_no_intervention()`
  (CMF-2), for the comfort code that follows.
- Four text presets in `game/xr/presets/`: `comfort_anchored.tres`, `comfort_guided.tres`,
  `comfort_pilot.tres`, `comfort_unrestricted.tres`. Every file states every field, so a
  change to a class default cannot silently change a preset.
- Numbers the table leaves open: snap 30 degrees; preset 1 pitch snaps (the table allows
  "snap or slow", but slow would be smooth rotation, which CMF-3 forbids); preset 2 yaw
  capped at 60 deg/s and pitch at 45 deg/s; vignette strength 0.8 / 0.5 / 0.25 / 0;
  hit shake 0 / 0.3 / 1 / 1; preset 3 auto-level on; 120 Hz allowed only on preset 4.
- New `game/tests/test_comfort_preset.gd`, twelve tests: loading, the folder holds exactly
  four presets, the test table covers every field, every field matches the table, every
  file states every field, preset 1 never rotates smoothly, preset 4 has no intervention,
  the helpers on the other presets, a custom copy of each preset with every field changed
  leaves the original intact, no reference to `core/` classes or paths, and no field named
  like a simulation value.

## Test results

Godot 4.7.2-stable, run locally exactly as CI does: 85 tests, 0 failed; the import leaves
no new files beside the committed `.gd.uid` files. Two hand mutations of the preset files
(preset 1 yaw smooth; preset 4 softening on and a field removed) were each caught.

## Open questions
