## Summary

- `dev_menu.json` gains a **Controls** entry and an optional `schemes` list
  (thumbsticks, gripped), checked against `ControlSchemeSwitch.SCHEMES`. Left/right steps
  through them; confirming returns `controls:<scheme>`. The menu opens on the scheme in use.
- New `xr/controls_choice.gd` (`ControlsChoice`) saves `{"scheme": ...}` in
  `user://meltdown_controls.json`, like `PanelCorner`; a bad file is ignored with a warning.
- `ControlSchemeSwitch.from_launch` now uses the saved scheme when no argument or intent
  extra names one; an argument wins; no file means thumbsticks. `switch_to` changes the
  scheme, lets go of both gripped grab points and prints
  `MELTDOWN_CONTROLS {...,"source":"menu"}`.
- `DevMenuWiring` takes the scheme and mapping in `_init` and applies `controls:<scheme>`
  while the menu is open (so the ship is on neutral input), saves it, and keeps the menu
  open. `main.gd` changes one line and stays at 300.
