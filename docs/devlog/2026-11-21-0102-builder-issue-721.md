## Summary

- New `game/xr/comfort_custom.gd` (`ComfortCustom`, `RefCounted`): reads
  `user://meltdown_comfort_custom.json` (`{"base": 1..4, "display_name": "...", "<field>": ...}`),
  duplicates the base preset and sets each named field. The settable fields are taken from
  `ComfortPreset`'s exported properties, so every row of the comfort table is covered and a
  future row needs no change here.
- Types follow the property: booleans, numbers, whole numbers, text; enums by their name
  (`"SNAP"`), so reordering an enum cannot change a saved file's meaning. `@export_range`
  bounds are enforced, `cockpit_file` must be a shipped `res://` file, then
  `validation_error()` runs. Any failure names the field and the base preset is used unchanged;
  a bad base or unreadable file falls back to the start preset; a missing file gives null.
- `ComfortPresetFiles.load_custom(path)` returns the preset. JSON, not `.tres` (a user
  resource can carry a script). Not wired: `main.gd` and `comfort_wiring.gd` untouched.
