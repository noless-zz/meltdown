## Summary

- New `game/xr/foveation_switch.gd` (`FoveationSwitch`, `RefCounted`): `--foveation=<0..3>` and
  `--foveation-dynamic=on|off`, or the intent extras `meltdown_foveation` and
  `meltdown_foveation_dynamic`, read the way `LevelSwitch` reads `--level` (argument wins, the
  last one counts). Without them nothing is written, so the project settings (level 0, dynamic
  off since #731) stay. A bad value is ignored with a `push_warning` naming it; the other switch
  still applies.
- `begin(runtime)` writes only the switched values to any object with `foveation_level` and
  `foveation_dynamic`, then prints
  `MELTDOWN_FOVEATION {"level":n,"dynamic":b,"source":"default"|"switch"}` from what the
  interface reads back. `advance(delta)` reads the level back once a second and prints the
  line again only when it differs from the last one printed.
- The intent reading is repeated from `ViewLog` because `xr/` may not depend on `meta/`.
- `main.gd`: built from the launch, applied in `_on_session_begun` next to the refresh rate,
  advanced each frame. Three comments folded into end-of-line comments to stay at 300 lines,
  away from the lines #749 changes.
