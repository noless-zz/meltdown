## Issue

#868 (M3, RUN-4, MAP-2, ARC-1, ARC-2): a solid box entry across a box's whole
cross-section splits that box for the route model.

## Summary

- New `game/core/box_split.gd` (`BoxSplit`): for one box and the solid box entries, the
  splits as (entry, axis, place in mm). An entry is tested alone on each axis by handing
  `OpeningClearance.blocked` a two-millimetre slice of the box at the entry's place, so the
  clearance rule is the one already used for openings, not a copy. Spheres never split.
  Also `part` (which side of the splits a point is on), `separates`, `holds`, `centre`.
- `KnownRoute.find`: nodes now belong to box parts, not boxes. A split is kept only when
  it separates two of the box's own points (opening centres, start, exit), so a door that
  already seals a corridor's end opening does not add a second mark. Kept splits go into a
  new `blocked_splits` list as (box, entry) pairs; their centres follow the openings'
  centres in `blocked_centres_mm`. Opening numbers are unchanged.
- `DebrisRouteGuard` needed no change: it asks `KnownRoute`, so it now holds a splitting
  slab that would close a ship's last way out.

## Open questions
