## Summary

- New `game/tests/seed_card.gd` (a `SceneTree` script). It builds each level the way the
  validator sweep does, through `SeedLevel`'s inputs, generator, level and validation, plus
  `seed_sweep.gd`'s public `debris_route`. Nothing is copied or edited. `--seeds=N --first=S`
  prints `MELTDOWN_SEED_CARD {...}` per seed. `escape_m` is `EscapePath` from the reactor to
  the exit, and `countdown_s` is `meltdown_ticks_for_path` for it (RUN-5). Debris entries are
  counted as fires, doors (box entries) or spheres.
- `--pick=N` picks greedily from valid seeds. Each pass takes the seed that covers the most
  missing kinds (loop, door, fire, longest escape), then a seed outside the m3 suite, then
  the lowest seed. The m3 suite's seeds, read from `m3.json`, are used only if the other
  seeds cannot cover all four kinds. It prints the chosen cards and then
  `MELTDOWN_SEED_PICK {"seeds":[...],"missing":[...]}`, and exits 1 if anything is missing.
- New `tools/seed_card.sh` passes its arguments through, like `tools/validate_seeds.sh`.
